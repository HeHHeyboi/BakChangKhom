# Mainboard_Pib.txt — บทปิ๊บ มินิเกม Core Part Mainboard + CPU
# ฟอร์แมต  ชื่อตัวละคร,ข้อความ   (คอมมาเดียวเท่านั้นต่อบรรทัด)

# @INSPECT_FINS
ปิ๊บ,ดูครีบฮีตซิงก์สิ ฝุ่นอุดเต็มร่องเลย ลมผ่านไม่ได้ความร้อนก็ออกไม่ทัน

# @INSPECT_PASTE
ปิ๊บ,ขอบ CPU มีซิลิโคนแห้งแตกเป็นขุย อันนี้ไม่นำความร้อนแล้วนะ

# @INSPECT_STANDOFF
ปิ๊บ,ใต้เมนบอร์ดมีรอยขูดตรงที่แผ่นแตะเคส สงสัยว่า standoff จะหายไปตัวหนึ่ง

# @BRIEFING
ปิ๊บ,ความร้อนจาก CPU ไม่ได้ลอยหายไปเองนะขม มันต้องถูกพาออกไปทางฮีตซิงก์
ปิ๊บ,ผิวโลหะสองชิ้นที่ดูเรียบ ๆ จริง ๆ แล้วมีรูเล็ก ๆ เต็มไปหมด อากาศที่ค้างในรูนั่นแหละที่กันความร้อน
ปิ๊บ,ซิลิโคนมีไว้ไล่อากาศออก ไม่ได้มีไว้เป็นกาว ทาบาง ๆ ก็พอ
ปิ๊บ,ของเครื่องนี้แห้งกรอบหมดแล้ว เลยพาความร้อนไม่ไหว เครื่องถึงดับตอนเล่นเกม

# @SAFETY_MAT
ปิ๊บ,วางเมนบอร์ดบนแผ่นรองกันไฟฟ้าสถิตนะ อย่าวางบนโต๊ะเปล่าหรือบนกล่องโฟม

# @REMOVE_COOLER
ปิ๊บ,ปลดคานล็อกทีละนิดแบบไขว้กันนะ อย่าปลดตัวเดียวจนสุด แผ่นจะงอ
ปิ๊บ,ก่อนยกให้หมุนซ้ายขวาเบา ๆ ก่อน ซิลิโคนเก่ามันดูดติดกันอยู่ ถ้าดึงตรง ๆ CPU จะหลุดติดขึ้นมาทั้งตัว

# @CLEAN_IPA
ปิ๊บ,ใช่ ไอโซโพรพิลแอลกอฮอล์ละลายซิลิโคนได้ดีและระเหยเร็วจนไม่ทิ้งความชื้น

# @CLEAN_TISSUE
ปิ๊บ,ใช้ได้อยู่ แต่กระดาษทิชชูทิ้งขุยไว้บนผิว เดี๋ยวต้องเช็ดซ้ำอีกรอบนะ

# @CLEAN_WATER
ปิ๊บ,หยุดก่อน น้ำระเหยช้าและจะค้างอยู่ใต้ฮีตซิงก์ที่เรากำลังจะปิดทับ
ปิ๊บ,ความชื้นใต้แผ่นโลหะร้อน ๆ คือสูตรสำเร็จของสนิมเลยนะ

# @CLEAN_THINNER
ปิ๊บ,ทินเนอร์แรงเกินไป มันกัดพลาสติกรอบซ็อกเก็ตกับสีบนแผ่นวงจรด้วย

# @CLEAN_SANDPAPER
ปิ๊บ,ไม่ได้เด็ดขาด ผิวฮีตซิงก์ที่ดูเรียบนั่นเขาเจียรมาอย่างดี ขูดทีเดียวคือพังถาวร

# @SEAT_CPU
ปิ๊บ,มองมุมซ้ายล่างของ CPU สิ มีสามเหลี่ยมเล็ก ๆ อยู่ ตรงซ็อกเก็ตก็มีเหมือนกัน
ปิ๊บ,หันให้สามเหลี่ยมตรงกัน แล้วปล่อยลงเฉย ๆ CPU ที่ดีจะลงล็อกเอง
ปิ๊บ,ห้ามกดเด็ดขาดนะ ถ้ามันไม่ลงแปลว่าหันผิด กดไปขาซ็อกเก็ตพับ แล้วแก้ไม่ได้อีกเลย

# @SEAT_CPU_WRONG_ROTATION
ปิ๊บ,มันเอียงค้างอยู่นะ แปลว่ายังหันไม่ถูกทาง ลองหมุนดูใหม่

# @SEAT_CPU_FORCED
ปิ๊บ,โอ๊ย ขาในซ็อกเก็ตพับไปแล้ว อันนี้ของจริงคือต้องเปลี่ยนเมนบอร์ดเลยนะ
ปิ๊บ,จำไว้นะขม แรงไม่เคยช่วยอะไรในงานคอม ถ้าต้องออกแรงแปลว่าทำผิดทาง

# @SEAT_CPU_TOUCH_PINS
ปิ๊บ,จับที่ขอบข้างนะ อย่าเอานิ้วแตะผิวด้านบนหรือขาทองด้านล่าง

# @PASTE_TYPE_GOOD
ปิ๊บ,ถูกแล้ว ซิลิโคนนำความร้อนธรรมดานี่แหละ ปลอดภัยที่สุดสำหรับงานร้าน

# @PASTE_TYPE_LIQUID_METAL
ปิ๊บ,โลหะเหลวนำความร้อนดีกว่าจริง แต่มันนำไฟฟ้าด้วยนะ
ปิ๊บ,หยดเดียวไหลลงไปโดนขาเมนบอร์ดคือจบเลย งานร้านเราไม่เสี่ยงดีกว่า

# @PASTE_TYPE_GLUE
ปิ๊บ,กาวเนี่ยนะ ติดแล้วถอดไม่ออกอีกเลยนะขม ครั้งหน้าใครจะซ่อมต่อก็ทำอะไรไม่ได้

# @PASTE_TYPE_TOOTHPASTE
ปิ๊บ,มีคนทำจริงนะเรื่องนี้ แต่ยาสีฟันแห้งกรอบภายในสองสัปดาห์แล้วก็ไม่เหลืออะไรเลย

# @PASTE_AMOUNT_OK
ปิ๊บ,เท่าเม็ดถั่วเขียวเม็ดเดียวตรงกลางพอ
ปิ๊บ,ไม่ต้องเกลี่ยนะ พอกดฮีตซิงก์ลงไปมันจะแผ่เองสม่ำเสมอกว่าที่เราป้าย
ปิ๊บ,ถ้าเกลี่ยเองจะมีฟองอากาศแทรก กลายเป็นฉนวนเสียเอง

# @PASTE_AMOUNT_LITTLE
ปิ๊บ,น้อยไปนิดนะ มุมของ CPU อาจจะมีช่องว่างเหลืออยู่

# @PASTE_AMOUNT_MUCH
ปิ๊บ,เยอะเกินแล้ว เดี๋ยวมันจะล้นออกข้างไปเลอะซ็อกเก็ต ต้องมาเช็ดกันใหม่

# @MOUNT
ปิ๊บ,ขันแบบทแยงมุมนะ หนึ่งแล้วข้ามไปสาม แล้วค่อยสองกับสี่
ปิ๊บ,ขันหลวม ๆ ให้ครบสี่ตัวก่อน แล้วค่อยไล่ขันแน่น แรงกดจะได้เท่ากันทั้งแผ่น

# @MOUNT_WRONG_ORDER
ปิ๊บ,ขันไล่รอบแบบนั้นฮีตซิงก์จะเอียงนิดนึงนะ ความร้อนออกได้ไม่เต็มที่

# @VERIFY_GOOD
ปิ๊บ,อุณหภูมิลงมาอยู่ในเกณฑ์แล้ว เครื่องนี้เล่นเกมได้ยาว ๆ แล้วล่ะ

# @VERIFY_HOT
ปิ๊บ,ยังร้อนกว่าที่ควรอยู่นะ ลองย้อนไปดูซิลิโคนกับลำดับการขันน็อตอีกที

# @SUMMARY
ปิ๊บ,สรุปนะ ความร้อนเป็นศัตรูอันดับหนึ่งของคอม
ปิ๊บ,และซิลิโคนคือของสิ้นเปลืองที่ต้องเปลี่ยนทุกสองถึงสามปี ไม่ใช่ทาครั้งเดียวจบ
