# Bios_Pib.txt — บทปิ๊บ มินิเกม Core Part BIOS + OS + Upgrade
# ฟอร์แมต  ชื่อตัวละคร,ข้อความ   (คอมมาเดียวเท่านั้นต่อบรรทัด)
# บรรทัดขึ้นต้นด้วย # คือคอมเมนต์ parser ข้ามให้
# บรรทัดขึ้นต้นด้วย @ คือหัวข้อ phase สำหรับ PibHint ใช้ค้นหา

@INSPECT_BOOT
ปิ๊บ,ดูแถบ Boot Priority สิ อันดับหนึ่งคือ USB ที่ลูกค้าเสียบทิ้งไว้

@INSPECT_MEMORY
ปิ๊บ,แถบ Memory ขึ้นสิบหกกิกะไบต์ครบ แต่ความเร็วแค่ 2133 ทั้งที่แรมเขียนข้างกล่องว่า 3200

@INSPECT_STORAGE
ปิ๊บ,SATA 1 เห็นฮาร์ดดิสก์อยู่ปกติ แปลว่าดิสก์ไม่ได้หายไปไหน ระบบน่าจะยังอยู่ครบ

@BRIEFING
ปิ๊บ,หน้าจอฟ้า ๆ นี่ไม่ใช่เครื่องพังนะขม มันคือ BIOS โปรแกรมที่อยู่ในเมนบอร์ด
ปิ๊บ,ทุกครั้งที่เปิดเครื่อง BIOS จะทำงานก่อน Windows เสมอ คอยตรวจว่าฮาร์ดแวร์ครบมั้ย
ปิ๊บ,ที่มันมาค้างตรงนี้แปลว่ามันหาระบบปฏิบัติการไม่เจอ ไม่ใช่ว่าดิสก์เสีย

@CHECK_HW
ปิ๊บ,ไล่ดูทีละแถบนะ แรมครบมั้ย ดิสก์เห็นมั้ย พัดลมหมุนกี่รอบ
ปิ๊บ,ถ้าตรงนี้เห็นครบหมด แปลว่าฮาร์ดแวร์ไม่มีปัญหา เหลือแค่เรื่องการตั้งค่า

@BOOT_ORDER
ปิ๊บ,ตรงนี้แหละคือต้นเหตุ อันดับหนึ่งของการบูตคือ USB ที่ลูกค้าเสียบทิ้งไว้
ปิ๊บ,เครื่องมันเชื่อฟังเราเป๊ะ ๆ เราบอกให้หาจาก USB ก่อน มันก็หาแล้วไม่เจอระบบ เลยค้าง
ปิ๊บ,ถอด USB ออกเฉย ๆ ก็หายนะ แต่พอลูกค้าเสียบอีกก็เป็นอีก เราแก้ที่ลำดับดีกว่า

@BOOT_ORDER_USB_ONLY
ปิ๊บ,แบบนี้ก็บูตได้อยู่ แต่เราแก้ปลายเหตุนะ วันหลังลูกค้าเสียบ USB อีกก็กลับมาเป็นเหมือนเดิม

@BOOT_ORDER_NETWORK
ปิ๊บ,เอา Network ขึ้นก่อนเครื่องจะไปนั่งรอหาเซิร์ฟเวอร์ในเน็ตนานมาก
ปิ๊บ,อันนั้นเขาใช้ในองค์กรที่ลงเครื่องทีละร้อยเครื่องพร้อมกัน ไม่ใช่เครื่องบ้าน

@XMP
ปิ๊บ,แรมกล่องนี้เขียนว่า 3200 แต่ BIOS ขึ้นแค่ 2133 ไม่ได้โดนหลอกนะ
ปิ๊บ,ค่ามาตรฐานมันตั้งไว้ต่ำเพื่อให้ทุกเครื่องบูตติดแน่ ๆ ความเร็วเต็มต้องไปเปิดโปรไฟล์ XMP เอง

@XMP_SKIPPED
ปิ๊บ,ไม่เปิดก็ใช้ได้อยู่ แต่ลูกค้าจ่ายค่าแรมเร็วไปแล้วไม่ได้ใช้ ก็น่าเสียดายนะ

@XMP_FAILED
ปิ๊บ,บูตไม่ขึ้นเลยใช่มั้ย ไม่ต้องตกใจ XMP ก็คือการโอเวอร์คล็อกแบบหนึ่ง ไม่ได้การันตีทุกเครื่อง
ปิ๊บ,ถอดถ่าน CMOS สักสิบวินาทีเพื่อล้างค่า แล้วค่อยลองโปรไฟล์อื่นหรือปล่อยไว้ก็ได้

@SAVE_EXIT
ปิ๊บ,อย่าลืมเลือก Save ก่อนออกนะ ไม่งั้นที่ตั้งมาทั้งหมดหายหมด

@SAVE_DISCARD
ปิ๊บ,อ้าว เลือก Discard ไปแล้ว ค่าที่ตั้งไว้หายหมดเลย ต้องทำใหม่นะ

@SAVE_DEFAULT
ปิ๊บ,ปุ่ม Load Optimized Defaults นี่มีประโยชน์นะ เวลาตั้งค่ามั่วจนบูตไม่ขึ้นก็กดตัวนี้กลับมาเริ่มใหม่ได้

@OS_SELECT_SSD
ปิ๊บ,ใช่ ลงลง SSD ดีกว่า เครื่องจะบูตเร็วกว่าฮาร์ดดิสก์หลายเท่า

@OS_SELECT_CUSTOMER_DISK
ปิ๊บ,หยุดก่อนขม ลูกนั้นมีข้อมูลลูกค้าอยู่ ลงทับคือหายหมดและกู้ยากมาก
ปิ๊บ,ของแบบนี้พลาดครั้งเดียวคือจบเลย ไม่ใช่แค่เครื่องเสีย แต่ความเชื่อใจเสียด้วย

@OS_INSTALLING
ปิ๊บ,ระหว่างรอ ผมเล่าให้ฟังหน่อย ช่างที่ดีจะถามลูกค้าเรื่องข้อมูลสำคัญก่อนลงเครื่องเสมอ
ปิ๊บ,รูปลูกหลาน เอกสารงาน พวกนี้พอหายแล้วเงินซื้อคืนไม่ได้นะ

@UPGRADE
ปิ๊บ,ดูกราฟสิ แท่งไหนเตี้ยสุดนั่นแหละคือคอขวด อัปตรงนั้นถึงจะรู้สึกว่าเร็วขึ้น
ปิ๊บ,ถ้าไปอัปชิ้นที่แท่งสูงอยู่แล้ว ลูกค้าจ่ายเงินแล้วไม่รู้สึกอะไรเลย แล้วเขาจะไม่กลับมาอีก

@UPGRADE_WRONG
ปิ๊บ,ชิ้นนั้นแรงพออยู่แล้วนะ อัปไปก็ไม่ได้ช่วยอะไร เพราะคอขวดอยู่อีกที่หนึ่ง

@UPGRADE_NONE_NEEDED
ปิ๊บ,บางทีคำตอบที่ถูกคือยังไม่ต้องซื้ออะไรครับ นะขม
ปิ๊บ,ลูกค้าที่ได้ยินแบบนี้จะจำเราไปอีกนาน แล้วพาคนอื่นมาด้วย

@SUMMARY
ปิ๊บ,เครื่องบูตเข้าวินโดวส์แล้ว แรมวิ่งเต็มความเร็วด้วย
ปิ๊บ,จำไว้นะ งานซ่อมที่ดีคือแก้ให้มันไม่กลับมาเป็นอีก ไม่ใช่แค่ทำให้มันหายวันนี้
