### 3.2 กติกาการซักถาม

1. ลูกค้าเปิดด้วย **คำบ่นกว้าง ๆ** ที่ยังชี้อะไรไม่ได้ ("มันค้างบ่อย", "เปิดไม่ติด")
2. ผู้เล่นเลือกคำถามจาก **6 หมวด** — แต่ละหมวดมีคำถามย่อย 2–3 ข้อ
3. คำตอบบางข้อมี **คำสำคัญ (key symptom)** ซ่อนอยู่ → ระบบไฮไลต์คำนั้นในกล่องข้อความ แล้วเด้งลง **สมุดจดอาการ** อัตโนมัติ
4. คำถามที่ไม่เกี่ยว หรือถามซ้ำหมวดเดิมเกิน 2 ครั้ง → **ความอดทนลูกค้าลด 1** (เต็ม 5)
5. เก็บคำสำคัญครบ **2 ข้อขึ้นไป** ปุ่ม "สรุปอาการ" จะ enable (กดก่อนได้ แต่เป็นการเดา)
6. กด "สรุปอาการ" → เลือก Part ที่สงสัยจากรายการ → ได้ **ใบงาน (WorkOrder)**

### 3.3 การเดาเร็ว vs เก็บข้อมูลครบ

| กรณี | ผล |
|---|---|
| เก็บคำสำคัญครบทุกข้อแล้วสรุปถูก | ✅ โบนัส "ช่างรอบคอบ" +15 คะแนน |
| เก็บ 2 ข้อแล้วสรุปถูก | ✅ ผ่านปกติ |
| เดาก่อนเก็บครบ แล้วถูก | 🟡 ผ่าน แต่ปิ๊บเตือน "คราวนี้เดาถูก แต่ช่างที่ดีไม่พึ่งดวงนะ" |
| สรุปผิด Part | ❌ เข้า S2 ได้ แต่พอเปิดดูจะพบว่าชิ้นนั้นปกติ → เสียเวลา 1 ช่วง ความไว้ใจลูกค้า −1 แล้วกลับมาถามใหม่ได้ |
| ความอดทนลูกค้าหมด | ❌ ลูกค้าบอก "งั้นผมลองร้านอื่นก่อนนะ" → งานหลุด (เล่นใหม่วันถัดไปได้) |

> ออกแบบให้ **ผิดแล้วเสียเวลา ไม่ใช่ผิดแล้วจบเกม** — สอดคล้องกับปรัชญาเดียวกับ Phase 0 ในมินิเกม Part RAM

### 3.4 หมวดคำถาม 6 หมวด

| หมวด | ตัวอย่างคำถาม | มักได้อะไร |
|---|---|---|
| อาการ | "ค้างแบบไหนครับ ภาพค้างหรือดับไปเลย" | แยกจอ/ระบบ/ไฟ |
| ช่วงเวลา | "เป็นตอนเพิ่งเปิด หรือใช้ไปสักพัก" | แยกความร้อน/หน้าสัมผัส |
| สิ่งที่เปลี่ยนล่าสุด | "ช่วงนี้มีอัปเกรดหรือย้ายเครื่องมั้ย" | แยกของหลวม/ลงของใหม่ |
| เสียง กลิ่น ไฟ | "ตอนเปิดมีเสียงบี๊บ หรือกลิ่นอะไรมั้ย" | **คำสำคัญเยอะที่สุด** |

### 4.2 กติกา

1. เคสวางกลางจอ แต่ละ Part เป็น **hotspot คลิกได้**
2. Part ที่ยังถอดไม่ได้จะเป็นสีจาง — คลิกแล้วปิ๊บบอกว่าติดอะไรอยู่ ("ต้องถอดการ์ดจอออกก่อนถึงจะดึงแรมได้")
3. ถอด Part ต้อง **ลากเครื่องมือที่ถูกต้อง** ไปที่ Part นั้น (เครื่องมือผิด → ปิ๊บห้าม ไม่เสียหายในครั้งแรก เหมือนระบบใน `MINIGAME1_DESIGN.md` หัวข้อ 14)
4. Part ที่ถอดออกมาไปวางบน **โต๊ะด้านข้าง** คลิกดูได้ (เข้า S3)
5. น็อตที่ไขออกเก็บใน **ถ้วยแม่เหล็ก** อัตโนมัติ — ถ้าไม่มีถ้วยในถาด น็อตมีโอกาสหาย 1 ตัว (ตอนประกอบกลับจะเจอปัญหา)

### 4.3 ขั้นบังคับก่อนแตะอะไรในเคส

ทำไม่ครบ → ปิ๊บเตือนและกดชิ้นส่วนไม่ได้

1. ปิดเครื่อง (ถ้ายังเปิดอยู่)
2. ถอดปลั๊กไฟ
3. ใส่สายรัดข้อมือกันไฟฟ้าสถิต **หรือ** แตะโครงเคส

### 4.5 ตาราง Part ทั้งหมด

**Core Part — มีมินิเกมซ่อมเต็มรูปแบบ (5 ชิ้น)**

| id | ชื่อ | เครื่องมือที่ต้องใช้ | ต้องถอดอะไรก่อน | มินิเกม |
|---|---|---|---|---|
| `ram` | แรม | มือ (ปลดสลัก) · ยางลบ/แปรง/ลูกยาง | ฝาข้าง (+ GPU ถ้าบัง) | 8 phase — `MINIGAME1_DESIGN.md` |
| `mainboard` | เมนบอร์ด + CPU | ไขควงแฉก · บล็อกหกเหลี่ยม · ซิลิโคน · IPA | ทุกชิ้นด้านบน | ติดตั้ง standoff → วาง CPU ตามลูกศร → ซิลิโคน → ล็อกฮีตซิงก์ |
| `gpu` | การ์ดจอ | ไขควงแฉก · มือ (ปลดสลัก PCIe) · เคเบิลไท | ฝาข้าง · สายไฟ PCIe | เสียบ PCIe → ล็อกสลัก → ต่อไฟ → จัดสาย/airflow |
| `front_panel` | Front panel + Dual channel | คีมปากแหลม · ไฟฉาย | ฝาข้าง | เสียบพินตามผัง (มีขั้ว +/-) → จัดแรมลงสลอตคู่สีเดียวกัน |
| `bios` | BIOS / OS | USB boot · คีย์บอร์ด | — (ทำหลังประกอบเสร็จ) | boot order → XMP → ลง OS → เช็ค bottleneck |

**Normal Part — ถอด/ตรวจ/ทำความสะอาดแบบสั้น (8 ชิ้น)**

| id | ชื่อ | เครื่องมือ | สิ่งที่ทำได้ |
|---|---|---|---|
| `side_panel` | ฝาข้างเคส | ไขควงแฉก | ถอด/ใส่ |
| `psu` | Power supply | ไขควงแฉก · PSU tester | ถอด · ทดสอบว่าจ่ายไฟได้มั้ย |
| `cables` | สายไฟ 24-pin / CPU / PCIe / SATA | มือ · เคเบิลไท | ถอด · เสียบ · จัดสาย |
| `case_fan` | พัดลมเคส | ไขควงแฉก · แปรง · ลูกยาง | ถอด · เป่าฝุ่น · เปลี่ยนตัวใหม่ |
| `cpu_cooler` | ฮีตซิงก์ + พัดลม CPU | ไขควงแฉก · แปรง · IPA | ถอด · ล้างครีบ · เช็ดซิลิโคนเก่า |
| `storage` | HDD / SSD | ไขควงแฉก · มือ | ถอด · สลับพอร์ต · ฟังเสียงหัวอ่าน |

## 5. S3 · PartView — เข้าไปทำงานกับชิ้นส่วน

คลิก Part → ซูมเข้าไปที่ชิ้นนั้นเต็มจอ ปิ๊บลอยอยู่มุมจอตลอด

### 5.1 Core Part → มินิเกมเต็มรูปแบบ

เข้า `PartMinigame` ที่ลงทะเบียนไว้กับ Part นั้น โครงมาตรฐาน (ปรับจาก `MINIGAME1_DESIGN.md`):

```
BRIEFING → ตรวจสภาพ → ลงมือ (หลายขั้นย่อย เลือกอุปกรณ์) → ตรวจผล → สรุป
```

* ครั้งแรกที่เจอ Part นี้ → บังคับดู tutorial slide + ปิ๊บสอนเต็ม
* ครั้งถัดไป → ข้ามได้ (อ่านจาก `Global.part_seen`)

### 5.2 Normal Part → งานสั้น 3 ทางเลือก

| การกระทำ | ใช้เมื่อ | ผล |
|---|---|---|
| **ตรวจสภาพ** | ทุกชิ้น | ปิ๊บอ่านสภาพให้ฟัง (ปกติ / สงสัย / เสีย) + จดลงใบงาน |
| **ทำความสะอาด** | มีฝุ่น/คราบ | ใช้เครื่องมือทำความสะอาด — แถบสะอาดขึ้น ลูกค้าพอใจ +1 |
| **เปลี่ยนของใหม่** | ชิ้นนั้นเสีย | หักเงินค่าอะไหล่จากกระเป๋าร้าน (ต้องมีสต็อกจาก Market) |

> Normal Part **ไม่มีคะแนนความรู้** แต่มีผลกับความพอใจลูกค้าและค่าแรง — ทำให้ผู้เล่นอยากสำรวจ ไม่ใช่วิ่งตรงไปที่ Part เดียว

### 5.3 การค้นพบระหว่างทาง (Hidden Finding)

บางเคสซ่อน **ปัญหาที่สองที่ลูกค้าไม่ได้บอก** ไว้ใน Normal Part เช่น
C01 (แรมสกปรก) มีพัดลมเคสฝืดซ่อนอยู่ด้วย — ถ้าผู้เล่นตรวจเจอและแก้ ได้โบนัส "ช่างช่างสังเกต" และลูกค้ากลับมาใช้บริการซ้ำเร็วขึ้น

## 6. S4 · Reassemble — ประกอบกลับและทดสอบ

1. **ประกอบย้อนลำดับ** — ระบบเช็ค dependency กลับด้าน (ใส่เมนบอร์ดก่อน จึงใส่ CPU cooler ได้)
2. **เช็คลิสต์ก่อนปิดฝา** (ปิ๊บอ่านให้ทีละข้อ):
   - สายไฟ 24-pin + CPU 8-pin เสียบครบ
   - แรมล็อกสลักทั้งสองข้าง
   - ไม่มีน็อตหลงเหลือในถ้วย
   - ไม่มีสายพันใบพัดลม
3. **Bench test** — เสียบปลั๊ก กดเปิด
   - ผ่าน → ไป S5
   - ไม่ผ่าน → ระบบบอกอาการใหม่ (เช่น "ไม่มีภาพ") แล้วย้อนกลับ S2 — **ไม่ใช่ Game Over** แต่เสียเวลา
4. ถ้าน็อตหายจากขั้นถอด → ตอนนี้จะพบว่าขันไม่ครบ ปิ๊บเตือนเรื่องการเก็บของ

## 7. S5 · Handover — ส่งมอบงาน

1. **อธิบายลูกค้า** — ผู้เล่นเลือกคำอธิบาย 1 จาก 3 แบบ
   | แบบ | ผล |
   |---|---|
   | ศัพท์ช่างล้วน | ลูกค้างง ความพอใจ +0 |
   | ภาษาชาวบ้าน + บอกวิธีดูแล | ✅ ความพอใจ +2 บอกต่อ |
   | ขู่ให้กลัวเพื่อขายของเพิ่ม | เงิน +มาก แต่ชื่อเสียง −2 |
2. **คิดเงิน** — ค่าแรงตามความยาก + ค่าอะไหล่ที่เปลี่ยนจริง
3. **การ์ดสรุป** — สิ่งที่เรียนรู้ 3 บรรทัด + คะแนน + ดาว 1–3 ดวง
4. บันทึกลง **สมุดงานซ่อม** (ประวัติงานที่ทำ ย้อนดูได้)

### ตารางคะแนนรวม 1 งาน

|---|---|---|
| การซักถามและวินิจฉัย (S1) | 25 | สรุปผิด Part −15 · เดาก่อนเก็บครบ −5 |
| ความปลอดภัย (S2) | 20 | ข้ามขั้นตัดไฟ/ESD −10 ต่อขั้น |

| งานซ่อมหลัก (S3) | 20 | ตามเกณฑ์ของมินิเกมนั้น |
| การประกอบกลับ (S4) | 10 | น็อตหาย −5 · Bench test ไม่ผ่าน −5 |
| การสื่อสารกับลูกค้า (S5) | 5 | อธิบายด้วยศัพท์ช่างล้วน −5 |

extends Node

signal case_started(c: CustomerCase)

var found_clues: Array[StringName] = []
