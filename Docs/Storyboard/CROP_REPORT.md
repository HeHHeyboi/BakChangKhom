## 🔧 ถ้าจะให้ผม crop ให้ได้

ส่ง **ไฟล์ sheet ต้นฉบับ** (ภาพรวมที่ generate มาเป็นตาราง) มาให้ แล้วบอกว่าเป็น grid กี่ช่อง เช่น 4×3
ผมจะ crop ตาม grid ให้ตรงช่อง ตัดขอบใส จัดกึ่งกลาง และ resize ตามสเปกใน `ASSET_GUIDE.md` ให้ครบทุกไฟล์ในรอบเดียว

## กฎที่ใช้ตอนจัดระเบียบรอบนี้

1. ตัดเศษของช่องข้างเคียงด้วยการเก็บเฉพาะก้อน alpha ที่ใหญ่ที่สุด (ใช้เมื่อก้อนใหญ่สุด ≥ 55% ของพื้นที่ทึบ)
2. trim ขอบใสออกให้หมด แล้วย่อให้วัตถุพอดีกรอบโดยเหลือขอบใส 8% ทุกด้าน
3. **ย่อเท่านั้น ไม่ขยาย** — ป้องกันภาพเบลอ
4. วางกึ่งกลาง canvas ตามขนาดที่สเปกกำหนด
5. asset ที่มีหลาย state ใช้ transform ชุดเดียวกันทุกไฟล์ ภาพจะได้ไม่กระโดด
