**ขอบคุณที่ช่วยทดสอบ!** เกมนี้สอนซ่อมคอมพิวเตอร์ผ่านการเปิดร้านซ่อมในหมู่บ้าน · ใช้เวลารวมประมาณ ___ ชั่วโมง (เล่นหลายครั้งได้ เกมบันทึกให้เอง)

**รหัสผู้ทดสอบของคุณ: `T__`** (ใช้รหัสนี้ทุกที่ · เกมไม่เก็บชื่อจริง)

1. **ติดตั้ง** — แตกไฟล์ zip ที่ได้รับ แล้วเปิด `BakChangKhom_v0.9.0_Tester.exe`
   ถ้า Windows ขึ้น "Windows protected your PC" ให้กด **More info → Run anyway** (เกมยังไม่ได้ซื้อใบรับรองผู้พัฒนา)
2. **เริ่มเกม** — กด "เริ่มเกม" → ใส่รหัสผู้ทดสอบ
3. **แบบทดสอบก่อนเล่น** — เกมเปิดแบบทดสอบในเบราว์เซอร์ให้ (รหัสใส่ไว้แล้ว) · ทำให้เสร็จ กดส่ง แล้วกลับมากด "ทำแล้ว เริ่มเล่น"
   *ทำก่อนเล่นเท่านั้น และทำครั้งเดียว · ไม่ต้องหาคำตอบจากที่อื่น ตอบตามที่รู้*
4. **เล่น** — เล่นตามสบาย กด **Esc** เพื่อพัก/บันทึก · ปิดเกมแล้วกลับมากด "เล่นต่อ" ได้
5. **ครบ 3 เดือนในเกม** (หลังหน้าสรุปเดือนมีนาคม) จะมีหน้าต่างขึ้นมา:
   1) กด **"ส่งออกข้อมูลการเล่น"** → ได้ไฟล์ `BakChangKhom_T___….zip` ในโฟลเดอร์ **เอกสาร (Documents)**
   2) กด **"เปิดแบบทดสอบหลังเล่น"** → ทำแบบทดสอบ + แบบสอบถาม แล้ว **แนบไฟล์ zip** ในฟอร์ม
   (ปิดไปแล้วเปิดใหม่ได้ที่ Esc → "แบบทดสอบหลังเล่น")
6. อยากเล่นต่อจนจบปีก็ได้ · ถ้าเล่นต่อ ส่งไฟล์ zip ล่าสุดอีกครั้งได้ที่ Esc → "ส่งออกข้อมูลการเล่น"

**เจอปัญหา** (เกมค้าง · ปุ่มกดไม่ได้ · ข้อความแปลก) จดว่าเกิดตอนไหน แล้วแจ้งทีมพร้อมรหัส · ถ้าเป็นไปได้แคปหน้าจอ

**ข้อมูลที่เก็บ:** รหัสผู้ทดสอบ · เวลาที่เล่น · ผลงานซ่อม/สอบในเกม · ตัวเลือกที่เลือก — ไม่เก็บชื่อ อีเมล หรือข้อมูลในเครื่อง · ส่งไฟล์เองเท่านั้น (เกมไม่ส่งข้อมูลออนไลน์)

## ส่วนที่ 2 · สำหรับทีม

### ก่อนส่งเกม
1. **ลิงก์ฟอร์ม** — Google Form → ⋮ → "รับลิงก์ที่กรอกข้อมูลไว้ล่วงหน้า" → ช่องรหัสผู้ทดสอบใส่ `T00` → "รับลิงก์" → คัดลอก → แทน `T00` ด้วย `{id}`
   ใส่ใน `Resources/tester_config.tres` (Inspector): `pre_form_url` · `post_form_url` · `post_after_months` (3) · เวลาโดยประมาณ
   ฟอร์มหลังเล่นควรมีช่อง **อัปโหลดไฟล์** (zip) + ข้อยินยอมให้ใช้ข้อมูล · เปิด "แบบทดสอบ (Quiz)" ให้คะแนนอัตโนมัติ → CSV มีคอลัมน์ Score
2. **ลองในเครื่องทีม** — `godot --path . -- --tester` (โหมดผู้ทดสอบแต่ยังกด F1 ได้) · F1 → "ผู้ทดสอบ: เปิดป๊อปอัปหลังเล่นตอนนี้" / "ไปปิดร้านวันสุดท้ายของ มี.ค."
3. **Export** — Project → Export → **"Windows Tester"** (feature `tester`: ถามรหัส · หน้าก่อนเล่น · ป๊อปอัปหลังเล่น · ปิด F1 · ป้ายเวอร์ชัน "ผู้ทดสอบ") → zip โฟลเดอร์ `BakChangKhom_v0.9.0_tester` ส่งให้ผู้ทดสอบ
4. แจกรหัส `T01`–`T__` (จดในตารางทีมว่าใครได้รหัสไหน — ตารางนี้ห้ามใส่ในเล่ม) · ล็อกข้อในฟอร์มก่อนเริ่มเก็บจริง

### หลังเก็บข้อมูล
```
python Tools/merge_playlog.py <โฟลเดอร์ zip> --pre pre.csv --post post.csv --out merged
```
- `pre.csv` / `post.csv` = ชีตคำตอบของฟอร์ม → ไฟล์ → ดาวน์โหลด → CSV (หาคอลัมน์รหัส/คะแนนเอง · กำหนดเองด้วย `--id-col` `--score-col`)
- ได้ `merged/participants.csv` (1 แถวต่อคน) · `prepost_stats.txt` (ค่าเฉลี่ย · SD · paired t-test · Cohen's dz) · `all_*.csv` (รวม playlog ทุกคน)
- ส่งซ้ำหลายไฟล์ = ใช้ zip ล่าสุดของแต่ละรหัส · ส่งฟอร์มซ้ำ = ใช้คำตอบล่าสุด

### ไฟล์ในเกม (`user://playlog/` — Windows: `%APPDATA%\Godot\app_userdata\BakChangKhom\playlog`)
| ไฟล์ | เนื้อหา |
|---|---|
| `session.csv` | ช่วงที่เล่น · วินาที · เหตุที่จบ (menu/quit/export) · เดือน/วันในเกม · เวลาเล่นสะสม · เงิน · ยศ |
| `learn_log.csv` | ผลสอบเลื่อนยศรายข้อ |
| `scenario_log.csv` | วินิจฉัยถูกครั้งแรกไหม · ข้ามขั้น · คะแนน |
| `events.csv` · `achievements.csv` · `ending.csv` | อีเวนต์ + ตัวเลือก · ใบประกาศ · ฉากจบ |

ทุกไฟล์ขึ้นต้นด้วย `time, tester_id, game_version`
