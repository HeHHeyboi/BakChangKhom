## ส่วนที่ 2 · สำหรับทีม

### ก่อนส่งเกม
1. **ฟอร์ม** — ก่อนเล่น / หลังเล่น (เปิดโหมด "แบบทดสอบ (Quiz)" ให้คะแนนอัตโนมัติ) · ทั้งสองฟอร์มมีช่อง **รหัสผู้ทดสอบ** · ฟอร์มหลังเล่นมี **อัปโหลดไฟล์** (zip) + แบบสอบถามความคิดเห็น + ข้อยินยอมให้ใช้ข้อมูล · ล็อกข้อก่อนเริ่มเก็บจริง
2. **Export** — Project → Export → "Windows Desktop" → zip โฟลเดอร์ `BakChangKhom_v0.9.0` + คู่มือส่วนที่ 1 (ใส่ลิงก์ · รหัส · เวลาโดยประมาณ)
3. แจกรหัส `T01`–`T__` (ตารางใครได้รหัสไหน เก็บในทีม ห้ามใส่ในเล่ม)

### หลังเก็บข้อมูล
1. ดาวน์โหลด zip จากคำตอบฟอร์มหลังเล่น → **เปลี่ยนชื่อไฟล์ให้มีรหัส** เช่น `T01.zip` (ดูรหัสจากแถวคำตอบเดียวกัน)
2. ดาวน์โหลดชีตคำตอบทั้งสองฟอร์มเป็น CSV
3. รัน
```
python Tools/merge_playlog.py <โฟลเดอร์ zip> --pre pre.csv --post post.csv --out merged
```
- หาคอลัมน์รหัส/คะแนนเอง (กำหนดเองด้วย `--id-col` `--score-col`) · ได้ `merged/participants.csv` (1 แถวต่อคน) · `prepost_stats.txt` (ค่าเฉลี่ย · SD · paired t-test · Cohen's dz) · `all_*.csv`
- คนเดียวส่งหลายไฟล์ = ใช้ไฟล์ที่ส่งออกล่าสุด (`info.txt` ใน zip) · ส่งฟอร์มซ้ำ = ใช้คำตอบล่าสุด

### ไฟล์ในเกม (`user://playlog/` — Windows: `%APPDATA%\Godot\app_userdata\BakChangKhom\playlog`)
| ไฟล์ | เนื้อหา |
|---|---|
| `session.csv` | ช่วงที่เล่น · วินาที · เหตุที่จบ (menu/quit/export) · เดือน/วันในเกม · เวลาเล่นสะสม · เงิน · ยศ |
| `start.csv` | เลือกดู/ข้ามบทนำ |
| `learn_log.csv` | ผลสอบเลื่อนยศรายข้อ |
| `scenario_log.csv` | วินิจฉัยถูกครั้งแรกไหม · ข้ามขั้น · คะแนน |
| `events.csv` · `achievements.csv` · `ending.csv` | อีเวนต์ + ตัวเลือก · ใบประกาศ · ฉากจบ |

ทุกไฟล์ขึ้นต้นด้วย `time, game_version`
