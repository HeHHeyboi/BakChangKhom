## 1. ความรู้ที่ Part นี้สอน

| หัวข้อ | สิ่งที่ผู้เล่นต้องเข้าใจหลังเล่นจบ |
|---|---|
| Standoff | เมนบอร์ดห้ามแตะโครงเคสโดยตรง ต้องมีน็อตรองยกสูง ไม่งั้นลัดวงจร |
| CPU orientation | สามเหลี่ยมทองบน CPU ต้องตรงกับสามเหลี่ยมบนซ็อกเก็ต — ฝืนกดขาพับถาวร |
| Zero insertion force | CPU **วางลงเอง** ไม่ต้องกด ถ้าไม่ลงแปลว่าหันผิด |
| Thermal paste | มีไว้ไล่อากาศระหว่างผิวสองชิ้น ไม่ใช่กาว · ทาน้อยไปร้อน ทามากไปเลอะ |
| ทำความสะอาดซิลิโคนเก่า | ต้องเช็ดออกก่อนทาใหม่ ใช้ IPA 99% ไม่ใช่น้ำ |
| ลำดับการขัน | ขันน็อตแบบไขว้ (ทแยงมุม) ให้แรงกดเท่ากันทั้งแผ่น |

**เคสลูกค้าที่ชี้มาที่ Part นี้:** C04 "เล่นเกมไปสักพักแล้วดับเอง"
คำสำคัญ: ดับหลังใช้ ~20 นาที · ลมออกร้อนจัด · ไม่เคยเปลี่ยนซิลิโคน 4 ปี

## 2. Flow 8 Phase

```
0 INSPECT      ตรวจสภาพ — เปิดฝา ดูฮีตซิงก์/ซิลิโคนแห้งกรอบ
1 BRIEFING     ปิ๊บสอน: ความร้อนออกจาก CPU ยังไง ทำไมซิลิโคนสำคัญ
2 SAFETY       ตัดไฟ + ESD + วางเมนบอร์ดบนแผ่นรอง
3 REMOVE       ปลดคานล็อกฮีตซิงก์แบบไขว้ → ยกฮีตซิงก์ (หมุนเบา ๆ ก่อนยก)
4 CLEAN        เช็ดซิลิโคนเก่าออกจาก CPU และฐานฮีตซิงก์  ← เลือกอุปกรณ์
5 SEAT_CPU     วาง CPU ให้สามเหลี่ยมตรงกัน → ปิดคานล็อก
6 PASTE        ทาซิลิโคน  ← เลือกชนิดและปริมาณ
7 MOUNT        ประกอบฮีตซิงก์ + ขันน็อตแบบไขว้ → VERIFY → SUMMARY
```

**เวลาเล่น:** รอบแรก 5–7 นาที · รอบซ้ำ 2–3 นาที

## 3. Phase 0 · INSPECT — ตรวจสภาพก่อนลงมือ

คลิกจุดสังเกต 3 จุด (แบบเดียวกับ Phase 0 ของ Part RAM)

| จุด | สิ่งที่เห็น | สิ่งที่แปลได้ |
|---|---|---|
| ครีบฮีตซิงก์ | ฝุ่นอุดเต็มร่อง | ลมผ่านไม่ได้ ความร้อนออกไม่ทัน |
| ขอบ CPU | ซิลิโคนแห้งแตกเป็นขุย | ไม่นำความร้อนแล้ว |
| ใต้เมนบอร์ด | มีรอยขูดตรงที่แผ่นแตะเคส | สงสัย standoff หายไป 1 ตัว |

ต้องคลิกครบ 3 จุดจึงกด "เริ่มซ่อม" ได้

## 4. Phase 4 · CLEAN — เลือกอุปกรณ์เช็ดซิลิโคนเก่า

**งานย่อย 2 ขั้น:** S1 เช็ดผิว CPU · S2 เช็ดฐานฮีตซิงก์

| อุปกรณ์ | S1 ผิว CPU | S2 ฐานฮีตซิงก์ | เหตุผล |
|---|:--:|:--:|---|
| คอตตอนบัด + IPA 99% | ✅ | ✅ | ละลายซิลิโคน ระเหยเร็ว ไม่ทิ้งคราบ |
| ผ้าไมโครไฟเบอร์แห้ง | 🟡 | 🟡 | เช็ดก้อนใหญ่ออกได้ แต่คราบบางยังเหลือ |
| กระดาษทิชชู | 🟡 | 🟡 | ใช้ได้แต่ทิ้งขุยกระดาษบนผิว ต้องเช็ดซ้ำ |
| ผ้าชุบน้ำ | ❌ | ❌ | น้ำระเหยช้า เหลือความชื้นใต้ฮีตซิงก์ |
| ทินเนอร์ / อะซิโตน | ❌ | ❌ | กัดพลาสติกรอบซ็อกเก็ตและสีบนแผ่น |
| กระดาษทราย | ❌ | ❌ | ขูดผิวเรียบให้เป็นรอย ยิ่งนำความร้อนแย่ลง |
| แปรงลวด | ❌ | ❌ | เหมือนกระดาษทราย + ทิ้งเศษโลหะนำไฟฟ้า |

กติกาเหมือน Part RAM: ✅ เต็ม · 🟡 ช้ากว่า 2 เท่า −3 · ❌ ปิ๊บห้ามทันครั้งแรก −8 · ซ้ำครั้งที่สอง = เสียหายจริง

## 5. Phase 5 · SEAT_CPU — วาง CPU

1. ลากคานล็อกลง → ฝาซ็อกเก็ตเปิด
2. **ลาก CPU ไปวาง** — ระบบเช็กมุมหมุน (0° / 90° / 180° / 270°)
3. ปิดคานล็อก (ต้องออกแรง — ปิ๊บบอกว่าปกติ)

| การกระทำ | ผล |
|---|---|
| หมุนถูก แล้ววาง | CPU ลงล็อกเอง มีเสียง *ตึก* เบา ๆ ✅ |
| หมุนผิด แล้ววาง | CPU เอียงค้าง เป็นสีแดงจาง ๆ + ปิ๊บเตือน — วางไม่ลง |
| **กดแรงตอนหันผิด** | ⚠️ ขาซ็อกเก็ตพับ → ต้องเริ่ม Part นี้ใหม่ + ค่าอะไหล่ (บทลงโทษหนักสุดในเกม เพราะของจริงคือพังถาวร) |
| จับที่ผิวด้านบน/ขาทอง | ปิ๊บเตือนให้จับที่ขอบข้าง |

## 6. Phase 6 · PASTE — เลือกชนิดและปริมาณซิลิโคน

### 6.1 เลือกชนิด

| ตัวเลือก | ผล |
|---|---|
| ซิลิโคนนำความร้อน (ไม่นำไฟฟ้า) | ✅ ถูกต้อง |
| ซิลิโคนโลหะเหลว | 🟡 นำความร้อนดีกว่า แต่นำไฟฟ้า — ปิ๊บเตือนว่าหยดโดนขาเมนบอร์ดคือพัง ไม่เหมาะกับงานร้าน |
| กาวร้อน / กาวตราช้าง | ❌ ถอดไม่ออกอีกเลย |
| ยาสีฟัน / วาสลีน | ❌ แห้งกรอบใน 2 สัปดาห์ (ปิ๊บเล่าว่าเคยมีคนทำจริง) |

### 6.2 เลือกปริมาณ (ลากแถบ)

| ปริมาณ | ผล |
|---|---|
| เม็ดถั่วเขียว ~1 เม็ด (กลาง) | ✅ แผ่เต็มพอดีเมื่อกดฮีตซิงก์ |
| น้อยเกิน | 🟡 มีช่องว่าง อุณหภูมิสูงกว่าปกติ 8°C ในหน้าจอผลลัพธ์ |
| มากเกิน | 🟡 ล้นออกข้าง เลอะซ็อกเก็ต ต้องเช็ดใหม่ (ย้อนไป Phase 4) |

> **ไม่ต้องเกลี่ย** — ปิ๊บย้ำว่าแรงกดจากฮีตซิงก์เกลี่ยเอง การเกลี่ยด้วยนิ้วทำให้มีฟองอากาศ

## 7. Phase 7 · MOUNT — ขันน็อตแบบไขว้

น็อต 4 ตัว ผู้เล่นคลิกตามลำดับที่เลือกเอง ระบบจำลำดับ

| ลำดับที่กด | ผล |
|---|---|
| ทแยงมุม 1→3→2→4 | ✅ แรงกดเท่ากัน |
| ไล่รอบ 1→2→3→4 | 🟡 ฮีตซิงก์เอียง อุณหภูมิสูงกว่าปกติ + ปิ๊บอธิบายเรื่องขันไขว้ |
| ขันแน่นทีเดียวทีละตัว | 🟡 เหมือนข้างบน — ที่ถูกคือขันหลวม ๆ ให้ครบก่อนแล้วค่อยไล่ขันแน่น |

**VERIFY:** กดเปิดเครื่อง → หน้าจอโชว์อุณหภูมิ CPU เดินขึ้นแล้วนิ่ง
ผ่านเมื่ออุณหภูมิ ≤ 65°C · ถ้า 66–80°C ผ่านแบบมีคำเตือน · > 80°C ไม่ผ่าน ต้องกลับไป Phase 6

ปิ๊บ,ของเครื่องนี้แห้งกรอบหมดแล้ว เลยพาความร้อนไม่ไหว เครื่องถึงดับตอนเล่นเกม

ปิ๊บ,มองมุมซ้ายล่างของ CPU สิ มีสามเหลี่ยมเล็ก ๆ อยู่ ตรงซ็อกเก็ตก็มีเหมือนกัน
ปิ๊บ,หันให้สามเหลี่ยมตรงกัน แล้วปล่อยลงเฉย ๆ CPU ที่ดีจะลงล็อกเอง
ปิ๊บ,ห้ามกดเด็ดขาดนะ ถ้ามันไม่ลงแปลว่าหันผิด กดไปขาซ็อกเก็ตพับ แล้วแก้ไม่ได้อีกเลย

# กดทั้งที่หันผิด
ปิ๊บ,โอ๊ย! ขาในซ็อกเก็ตพับไปแล้ว อันนี้ของจริงคือต้องเปลี่ยนเมนบอร์ดเลยนะ
ปิ๊บ,จำไว้นะขม แรงไม่เคยช่วยอะไรในงานคอม ถ้าต้องออกแรงแปลว่าทำผิดทาง

# Phase 6 ทาซิลิโคน
ปิ๊บ,เท่าเม็ดถั่วเขียวเม็ดเดียวตรงกลางพอ
ปิ๊บ,ไม่ต้องเกลี่ยนะ พอกดฮีตซิงก์ลงไปมันจะแผ่เองสม่ำเสมอกว่าที่เราป้าย
ปิ๊บ,ถ้าเกลี่ยเองจะมีฟองอากาศแทรก กลายเป็นฉนวนเสียเอง

# Phase 7 ขันน็อต
ปิ๊บ,ขันแบบทแยงมุมนะ หนึ่งแล้วข้ามไปสาม แล้วค่อยสองกับสี่
ปิ๊บ,ขันหลวม ๆ ให้ครบสี่ตัวก่อน แล้วค่อยไล่ขันแน่น แรงกดจะได้เท่ากันทั้งแผ่น

# SUMMARY

## 11. สเปกโค้ด

ใช้โครงเดียวกับ Part RAM (`MINIGAME1_DESIGN.md` หัวข้อ 8) — เปลี่ยนแค่ enum และตาราง resource

```gdscript
# Scripts/MiniGame/PartMainboard/part_mainboard.gd
class_name PartMainboardGame extends PartMinigameBase

enum Phase { INSPECT, BRIEFING, SAFETY, REMOVE, CLEAN, SEAT_CPU, PASTE, MOUNT }
enum CleanStep { CPU_SURFACE, HEATSINK_BASE }
enum PasteAmount { TOO_LITTLE, JUST_RIGHT, TOO_MUCH }

var cpu_rotation := 0          # 0 / 90 / 180 / 270
var screw_order: Array[int] = []
var temp_result := 0.0
```

* อุปกรณ์เช็ดซิลิโคนใช้ `CleanTool` resource ตัวเดิม เพิ่มไฟล์ `.tres` ที่ `Resources/MiniGame/Tools/`
* ลำดับขันน็อตตรวจด้วย `_is_diagonal(order)` — คู่ทแยงคือ (0,2) และ (1,3)
* อุณหภูมิผลลัพธ์ = `base_temp + paste_penalty + screw_penalty + dust_penalty`
