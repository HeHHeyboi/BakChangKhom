## 1. คลังของ (Storage)

### 1.1 หลักคิด

- ของทุกอย่างที่ซื้อมา **ต้องมีที่วาง** → ช่องจำกัด = ต้องคิดก่อนซื้อ ไม่กักตุน
- **อะไหล่ 1 ชิ้น = 1 ช่อง** (ไม่ซ้อน · มีสภาพ มือสอง/ใหม่) · **ของสิ้นเปลืองซ้อนได้** (1 ชนิด+เทียร์ = 1 ช่อง จำนวนครั้งรวมกัน ≤ 99) · **เครื่องมือไม่กินช่อง** (อยู่ใน ToolBelt)
- ของกินอยู่ใน **กระเป๋าขม 3 ช่อง** แยก (ECONOMY_ENERGY 4.3)

### 1.2 ช่องคลัง

| ระดับ | ชื่อในเกม | ช่อง | ราคา | ปลด |
|---|---|---|---|---|
| เริ่ม | กล่องกระดาษใต้โต๊ะ | **8** | — | — |
| 2 | ชั้นเหล็กเก็บอะไหล่ | **14** | ฿800 | เริ่ม (ซื้อได้ในเดโม) |
| 3 | ตู้ลิ้นชักแยกชิ้น | **24** | ฿2,000 | ช่างฝึกหัด |

> แยกจาก "ชั้นวางเครื่องลูกค้า" (SHOP_UPGRADE ข้อ 4 = จำนวนงานรับพร้อมกัน) — คนละอย่าง

### 1.3 สถานะของในช่อง

| ป้าย | ความหมาย |
|---|---|
| 🟢 ใหม่ / 🟡 มือสอง | สภาพอะไหล่ (มือสองเคลม 15% · ECONOMY_ENERGY 2.1) |
| 🔖 จองให้: ลุงอำนวย | ผูกกับใบงานแล้ว — ขาย/ใช้กับงานอื่นไม่ได้ (ปลดจองได้) |
| 📦 รอส่ง | สั่งออนไลน์แล้ว ยังไม่มาถึง — **จองช่องไว้แล้ว** (ช่องเต็ม = สั่งไม่ได้) |
| ⚠ ถอดจากเครื่องลูกค้า | ชิ้นเก่าที่เปลี่ยนออก — ต้องคืนลูกค้าตอนส่งมอบ (ลืม = ชื่อเสียง −1 · สอนเรื่องคืนของเก่าให้ลูกค้า) |

### 1.4 ช่องเต็มแล้วทำไง

- ซื้อไม่ได้ (ปุ่มซื้อเทา + บอก "คลังเต็ม 8/8")
- **ขายคืน**: อะไหล่มือสอง 50% · ของใหม่ยังไม่แกะ 80% · ของสิ้นเปลืองขายไม่ได้ (ทิ้งได้)
- ชิ้นเก่าที่ลูกค้าไม่เอาคืน → เก็บเป็นอะไหล่มือสอง "ไม่รู้สภาพ" (ต่อกับมินิเกมซ่อมขาย ECONOMY_ENERGY 5.1 ทีหลัง)

### 1.6 ต่อกับงานซ่อม

- `CustomerCase` เพิ่ม `needs_part: StringName` (เช่น `&"ram_ddr4_8gb"`)
- S1 รับงาน: ระบบเช็กคลัง → **มี** = จองให้อัตโนมัติ · **ไม่มี** = ใบงานติดป้าย "ขาดอะไหล่" ทำได้ 3 ทาง: ไปตลาด (ได้ทันที) · สั่งออนไลน์ (มากะหน้า · งานขึ้นชั้น "รอของ") · ปฏิเสธงาน

### 3.2 เงินออก

| รายการ | 5 กะ | หมายเหตุ |
|---|---|---|
| ของสิ้นเปลือง | ~฿300–500 | บังคับ (ไม่มีของ = งานช้าลง) |
| ค่าอะไหล่ที่ควักก่อน | ~฿450–900 | **ได้คืนตอนส่งมอบ** = เงินหมุน ไม่ใช่รายจ่าย |

| บิลรายเดือน | — | ไม่ถึงสิ้นเดือนในเดโม |

### 3.3 เป้าหมายความรู้สึก

- เริ่ม ฿500 → **กะ 1–2 เงินตึง** ซื้ออะไหล่ได้ทีละชิ้น ต้องเลือกระหว่างของสิ้นเปลือง T1/T2
- **กะ 3–4** มีเงิน ~฿1,500–2,500 → การตัดสินใจแรก: **ชั้นเหล็ก ฿800 (คลังใหญ่) หรือของ T2 ทั้งชุด**
- จบเดโม เหลือ ~฿2,000–3,500 → การ์ดจบบทโชว์ "รายรับ − รายจ่าย" ให้เห็นภาพธุรกิจ
