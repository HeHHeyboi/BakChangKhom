## 2. อะไหล่คอมในร้านค้า

### 2.1 กติกา

- อะไหล่ **ลูกค้าเป็นคนจ่าย** แต่ **ขมต้องควักเงินซื้อก่อน** แล้วได้คืนตอนส่งมอบ → สร้างแรงกดดันเรื่อง **เงินหมุน** (เงินน้อย = รับงานเปลี่ยนชิ้นแพงไม่ได้ หรือต้องให้ลูกค้ามัดจำ — ข้อ 3)
- ขมบวกราคาได้ **≤ 15%** ตามปกติ · บวกมากกว่านั้นต้องผ่านการต่อรอง และลูกค้าไปเล่าต่อ (ชื่อเสียง −)

## 3. ต่อรองราคา (Concession) + คำสารภาพ (Confession)

### 3.1 ต่อรองตอนรับงาน

เกิดหลังซักอาการ + วินิจฉัยเบื้องต้น ก่อนลงมือ (S1 ShopCounter) · **ใช้เวลา 0 ช่อง** · ไม่บังคับ (กด "ราคามาตรฐาน" ข้ามได้)

```
┌─ ตกลงราคา · ลุงอำนวย ──────────────────────────────────┐
│ งาน: เปลี่ยน PSU (Lv4)                                  │
│ ค่าแรงมาตรฐาน ฿420 + PSU มือสอง ฿350 = ฿770              │
│                                                        │
│ ลุงอำนวย: "แพงไปหน่อยนะหลาน ลุงมีแค่ห้าร้อยกว่า ๆ"  ❤️❤️    │
│                                                        │
│ ข้อเสนอของขม (เลือก ≤ 2 ใบ):                             │
│  [💸 ลดค่าแรง 10%]   [♻️ ใช้มือสองแทนใหม่ ✓]            │
│  [🧾 แบ่งจ่าย 2 งวด]  [🧹 แถมทำความสะอาด (+1 ช่อง)]       │
│  [⚡ งานด่วนกะนี้ +20%] [🛡 รับประกัน 30 วัน]              │
│                                                        │
│ เสนอ: ฿691       [ เสนอ ]   [ ราคามาตรฐาน ]   [ ปฏิเสธงาน ] │
└────────────────────────────────────────────────────────┘
```

**ข้อมูลที่ลูกค้าซ่อน:** งบจริง · เรื่องที่ใส่ใจ (ราคา / ความเร็ว / ความมั่นใจ) · ความอดทน ❤️ (ใช้ร่วมกับตอนซักอาการ)
**ผู้เล่นเดาได้จาก:** บทพูด ("ลุงมีแค่…") · อาชีพ · เหตุที่มาร้าน · ประวัติ (ลูกค้าเก่าในสมุดช่าง)

**การ์ดข้อเสนอ (ยอมให้ 1 อย่าง แลกกับอีกอย่าง)**

| การ์ด | ลูกค้าได้ | ขมเสีย | ใช้ได้เมื่อ |
|---|---|---|---|
| 💸 ลดค่าแรง 10% | ราคาลด | เงิน | ทุกงาน |
| ♻️ มือสองแทนใหม่ | ราคาลด | ความเสี่ยงเคลม 15% | งานที่มีอะไหล่ |
| 🧾 แบ่งจ่าย 2 งวด | จ่ายครึ่งเดียวตอนรับ | เงินหมุน (อีกครึ่งได้ 5 กะ · มีโอกาส 10% จ่ายช้า) | ลูกค้าเก่า/รู้จัก |
| 🧹 แถมทำความสะอาด | ความคุ้ม | เวลา +1 ช่อง · พลังงาน | ทุกงาน · ชื่อเสียง +1 |
| ⚡ ด่วนกะนี้ +20% | ความเร็ว | ต้องทำในกะนี้ (ไม่ทัน = ค่าแรง −30%) | ลูกค้าใส่ใจความเร็ว |
| 🛡 รับประกัน 30 วัน | ความมั่นใจ | ถ้าเคลม ซ่อมฟรี | ลูกค้าใส่ใจความมั่นใจ · ราคา +10% ได้ |
| 💰 ขอมัดจำ 50% | — | ความอดทน −1 | งานที่ขมต้องควักอะไหล่ก่อน (ข้อ 2.1) |

**รอบต่อรอง:** สูงสุด 3 รอบ · แต่ละรอบลูกค้าตอบ ยอม / ต่อกลับ / ❤️ −1 · ❤️ หมด = เดินออก
**ผล:** ราคาสุดท้ายอยู่ในช่วง **−20% ถึง +20%** ของมาตรฐาน

**มาตรวัดความยุติธรรม** (ซ่อนอยู่ · โชว์ในสมุดช่าง): ตั้งราคาเกินงบจริงลูกค้าแล้วลูกค้ายอม = ได้เงินวันนี้ แต่ **ลูกค้าเล่าต่อในหมู่บ้าน** → ชื่อเสียง −2 ใน 2–3 กะ · ลดให้คนที่งบน้อยจริง (ยาย · เด็ก) = ชื่อเสียง +1 · **สอนการตั้งราคาอย่างเป็นธรรมและอธิบายค่าใช้จ่ายให้ลูกค้าเข้าใจ**

ลูกค้าตัวอย่าง (ใช้ตัวละครที่มีสไปรต์แล้ว)

| ลูกค้า | งบ | ใส่ใจ | ลักษณะ |
|---|---|---|---|
| ยาย | ต่ำมาก | ราคา | ขมเลือก "ไม่คิดเงินยาย" ได้ → ความสัมพันธ์ + |
| ลุงอำนวย | ต่ำ | ราคา | ต่อเก่ง แต่ซื่อสัตย์ · จ่ายครบเสมอถ้าแบ่งจ่าย |
| ผู้ใหญ่บ้าน | กลาง | ความมั่นใจ | ต่อแรงแต่ทำดีด้วย = พาลูกค้ามาเพิ่ม |
| ครู · ผอ. | กลาง (เบิกโรงเรียน) | ความมั่นใจ | ต้องการใบเสร็จ · ไม่ต่อ แต่ไม่จ่ายเกินราคากลาง |
| ร้านเกม | สูง | ความเร็ว | ยอม +20% ด่วน |
| เด็ก · เด็กหญิง | ต่ำมาก (เงินค่าขนม) | ราคา | ต่อไม่เป็น — ตั้งราคาสูงได้ง่าย แต่ชื่อเสียงร่วงหนัก |

### 3.2 คำสารภาพ (Confession)

บางเคส (~20% ของงาน Lv2 ขึ้นไป) **ลูกค้ามีเรื่องที่ไม่ได้เล่า** · ช่างจริงเจอบ่อย

| ความลับ | อาการที่ลูกค้าเล่า | ถ้าสารภาพ |
|---|---|---|
| ทำน้ำ/กาแฟหกใส่คีย์บอร์ด | "จู่ ๆ ก็พิมพ์ไม่ได้" | วินิจฉัย −1 ช่อง · ตรงไปทำความสะอาด/เปลี่ยน |
| เครื่องตก | "เปิดแล้วมีเสียงแกรก ๆ" | รู้ว่าเป็นฮาร์ดดิสก์ → สำรองข้อมูลก่อน (ไม่ทำข้อมูลหาย) |
| หลานลงเกมเถื่อน | "มีโฆษณาเด้ง เครื่องอืด" | รู้ต้นเหตุไวรัส · ปิ๊บสอนเรื่องโปรแกรมถูกลิขสิทธิ์ |
| เคยให้ร้านอื่นแกะมาแล้ว | "ปุ่มเปิดไม่ติด" | รู้ว่าสายหน้าเคสเสียบผิด (Front Panel) |
| ถอดปลั๊กตอนอัปเดต | "เปิดแล้วขึ้นจอดำ" | ตรงไปงานซ่อมบูต |

**วิธีได้คำสารภาพ** — ตอนซักอาการมีคำถามแบบ "ชวนเล่า" กับแบบ "กล่าวหา"

| แบบถาม | ตัวอย่าง | ผล |
|---|---|---|
| ชวนเล่า (ถูก) | "ก่อนเป็นแบบนี้ มีอะไรเกิดขึ้นกับเครื่องบ้างไหมครับ ไม่เป็นไรนะ เกิดขึ้นได้" | ลูกค้าสารภาพ 🗣 · ❤️ ไม่ลด |
| กล่าวหา (ผิด) | "ทำน้ำหกใช่ไหมเนี่ย" | ลูกค้าปฏิเสธ · ❤️ −1 · ไม่ได้ข้อมูล |
| ไม่ถาม | — | วินิจฉัยเองได้ แต่ช้ากว่า (+1–2 ช่อง) |

**ผลต่อการต่อรอง:** ลูกค้าที่สารภาพแล้ว **รู้สึกผิด/ไว้ใจขม** → ยอมราคามาตรฐานง่ายขึ้น (รอบต่อรอง −1) · ถ้าขมใช้ความลับมากดราคาขึ้น (การ์ด "เพราะคุณทำเอง +20%") ได้เงินแต่ชื่อเสียง −3 — **ทางเลือกทางจริยธรรมเล็ก ๆ** ที่ส่งผลจริง

### 3.3 ต่อราคากับคนขาย

- **ตลาดหมู่บ้าน:** ซื้อ ≥ 3 ชิ้น ขอลดได้ 5% · ซื้อประจำ (ครบ 10 ครั้ง) = ขาประจำลด 10% ถาวร
- **รถพุ่มพวง:** ต่อได้ 1 ครั้งต่อการมา · สำเร็จ 50% (ลดเพิ่ม 10%) · ไม่สำเร็จ = ราคาเดิม
- **ร้านออนไลน์:** ต่อไม่ได้ (ราคาตายตัว)

## 5. มินิเกมที่ใช้เงิน

ไม่มีระบบพนัน/สุ่มกาชา (เกมการศึกษา กลุ่มผู้เล่นอาจเป็นนักเรียน) · ทุกอันใช้ **ทักษะวินิจฉัย/คำนวณ** ที่เรียนในเกม · มีเพดานกำไรต่อสัปดาห์เพื่อคุมเงินรวม ≤ ฿50k

### 5.1 🔧 ซื้อเครื่องเก่ามาซ่อมขาย (ตลาดนัดวันเสาร์)

- ฉากตลาดนัดของเก่าทุกเสาร์ (ช่วงวันหยุด ไม่กินช่องงาน) · มีของ 3–4 ชิ้น/เครื่อง ราคา ฿100–1,500
- **ดูได้ก่อนซื้อ 3 อย่าง** (เลือก): เปิดเครื่องดูไฟ · ฟังเสียง · ส่องขาทอง/ตัวเก็บประจุ · ถามคนขาย (บางทีโกหก)
- ซื้อแล้วซ่อมใน **ล่วงเวลา** หรือช่องว่างในกะ (ใช้มินิเกมเดิม) → วางขายที่ตู้โชว์ (ต้องมีอัปเกรดตู้โชว์) ขายได้ใน 2–5 กะ
- ซื้อของพังเกินซ่อม = ขาดทุน (ขายเป็นอะไหล่ได้ครึ่งหนึ่ง)
- กำไรต่อชิ้น ฿100–600 · **เพดาน: ขาย 1 ชิ้น/สัปดาห์** · ทั้งเกม ≤ ~฿2,000
- สอน: ประเมินสภาพของมือสองก่อนซื้อ

### 5.2 💻 มุมคอมให้เช่าในร้าน

- ลงทุนประกอบคอมมือสอง 1–2 เครื่อง (ใช้อะไหล่จากข้อ 2 · ~฿2,500/เครื่อง) ตั้งมุมร้าน
- เด็ก ๆ มาเช่าทำการบ้าน/เล่น ชั่วโมงละ ฿10 · ได้ ~฿60–100/กะ/เครื่อง (อัตโนมัติ)
- **มีปัญหาตามมา:** เด็กทำน้ำหก · โหลดของแปลกจนติดไวรัส · สายหลวม → **กลายเป็นงาน Lv1–2 ของร้านเอง (ไม่ได้ค่าแรง)** ต้องแบ่งเวลามาดูแล
- คืนทุน ~4–5 สัปดาห์ · ถ้าดูแลแย่ เครื่องเสียบ่อยจนไม่คุ้ม
- สอน: การลงทุนและค่าบำรุงรักษา · เชื่อมฉากจบ "ร้านเน็ตชุมชน"

### 5.3 👵 คลาสสอนคอมผู้สูงอายุ (ศาลาหมู่บ้าน)

- เปิดได้หลังมุมนั่งรอ + ยศช่างประจำหมู่บ้าน · ค่าใช้จ่าย ฿300 (ค่าน้ำ/ขนม/ปริ้นเอกสาร) · ใช้ช่วงพักเที่ยงวันศุกร์
- มินิเกม: สอนคุณตาคุณยาย 3 คนพร้อมกัน ทำงาน Lv1 (ลง LINE · วิดีโอคอล · ระวังลิงก์หลอก) — ขมต้องไล่ช่วยทีละคนก่อนแต่ละคนหมดความอดทน
- ไม่ได้เงินตรง ๆ · ได้ **ชื่อเสียง +3** และลูกค้าใหม่ 1–2 คนสัปดาห์ถัดไป · ยายภูมิใจ
- สอน: ทบทวนเนื้อหา Lv1 ด้วยการสอนคนอื่น

### 5.4 📦 ประมูลล็อตอะไหล่เหลือใช้ (เลือกใส่)

- สอน: ประเมินมูลค่าจากข้อมูลไม่ครบ (ต่างจากกาชาตรงที่ข้อมูลมีจริง คิดได้)

## 8. ลำดับทำ (เสนอ)

1. **ตัวเลขเงินใหม่** ใน `economy.tres` + `MONEY_CAP` — 1 ชั่วโมง
2. **พลังงาน + อาหารช่วงพักเที่ยง** (ร้านข้าวแกง · ข้าวกล่องยาย · ร้านกาแฟ) — เห็นผลกับ QTE ทันที
3. **อะไหล่ในร้านออนไลน์** (แรม · PSU · พัดลม · SSD ก่อน) + ควักเงินก่อน/ได้คืนตอนส่งมอบ
4. **ต่อรองแบบง่าย**: การ์ด 4 ใบ (ลดค่าแรง · มือสอง · ด่วน · มัดจำ) · 2 รอบ
5. **คำสารภาพ** 3 แบบ (น้ำหก · เครื่องตก · เกมเถื่อน) ใส่ในเคส Lv2–Lv3
6. มินิเกมใช้เงิน: ซ่อมขาย → มุมคอมเช่า → คลาสผู้สูงอายุ → (ประมูล)
