## 1. หลักคิด

| หลัก | เหตุผล |
|---|---|
| **QTE ต้องแทน "ทักษะมือ" ที่มีจริง** — แรงกด · การเล็งให้ตรง · จังหวะ · มือนิ่ง | เกมนี้สอนซ่อมคอม ถ้า QTE สุ่มกดปุ่มมั่ว ๆ จะสอนผิด · ทุก QTE ต้องตอบได้ว่า "ช่างจริงต้องระวังอะไรตรงนี้" |
| **ใส่เฉพาะจังหวะไคลแมกซ์ 2–3 จุดต่อ Part** | การตัดสินใจ (เลือกอุปกรณ์ · เลือกหัวสาย · อ่านผัง) ยังเป็นการคลิกคิดเหมือนเดิม · QTE เป็นตอน "ลงมือ" |
| **พลาดแล้วไม่ตาย** — Perfect / Good / Miss · Miss = หักคะแนนตามหมวดเดิม แล้วลองใหม่ | ผู้เล่นเป็นนักเรียน ไม่ใช่เกมแอ็กชัน · พลาด 3 ครั้งปิ๊บช่วยทำให้ (หักคะแนนเต็ม) ไม่มีวันติด |
| **ครั้งแรกช้า ครั้งต่อไปเร็วขึ้น** | ใช้ระบบปลดล็อกตามรอบ (`GAME_LOOP.md` ข้อ 5) · ครั้งแรกโซนกว้าง 1.5 เท่า มีปิ๊บบอกว่าต้องทำอะไร |
| **คลิกเมาส์ หรือ Space ใช้ได้ทุก QTE** | ไม่บังคับคีย์บอร์ด · ลำดับปุ่มใช้ลูกศร/WASD หรือคลิกปุ่มบนจอแทนได้ |
| **มีโหมดช่วย (Assist)** ในตั้งค่า | ช้าลง 2 เท่า + โซนกว้าง · สำหรับคนที่กดไม่ทัน (เกมการศึกษา ต้องเข้าถึงได้) |

## 2. QTE 6 แบบ (ทำเป็นชิ้นส่วนกลาง ใช้ซ้ำทุก Part)

| แบบ | เล่นยังไง | แทนทักษะจริง | หน้าตา |
|---|---|---|---|
| **A · จังหวะ (Timing)** | ตัวชี้วิ่งไป-กลับบนแถบ กดตอนอยู่ในโซนเขียว | เล็งให้ตรงตำแหน่ง | แถบโค้งกรอบทอง · โซนเขียว · ตัวชี้ส้ม |
| **B · กดค้างแล้วปล่อย (Hold)** | กดค้าง เกจขึ้น ปล่อยในโซนพอดี · เกินโซนแดง = แรงเกิน | ออกแรงกดให้พอดี | เกจแนวตั้งข้างชิ้นงาน |
| **C · วงหด (Ring)** | วงกลมหดเข้าหาเป้า กดตอนวงทับกรอบ | จังหวะสั้น ๆ ครั้งเดียว | วงทองหดเข้าหาจุดส้มบนชิ้นงาน |
| **D · ลำดับ (Sequence)** | ปุ่มขึ้นเป็นลำดับ กดตามให้ถูก (ลูกศร / คลิกจุดที่ขึ้นเลข) | ทำตามลำดับที่ถูก | วงตัวเลข 1–4 บนชิ้นงาน |
| **E · มือนิ่ง (Steady)** | ประคองวงเล็งให้อยู่บนเป้าที่สั่นเบา ๆ จนเกจเต็ม | มือนิ่ง ไม่กระแทก | วงเล็งโปร่ง + เกจวงกลมรอบเป้า |
| **F · ถู (Rub)** | ลากเมาส์ซ้าย-ขวาเป็นจังหวะ ไม่ช้าเกิน ไม่เร็วเกิน | ถูให้สะอาดแต่ไม่แรง | ลูกศร ⟷ + เกจความเร็ว (เขียวกลาง) |

ผลลัพธ์ทุกแบบ: **PERFECT** (ในโซนกลาง) · **GOOD** (ในโซน) · **MISS** (นอกโซน/หมดเวลา)

## 3. QTE ราย Part

### 3.1 RAM

| Phase | จังหวะ | QTE | Perfect / Good | Miss |
|---|---|---|---|---|
| REMOVE | ปลดสลัก 2 ข้าง | **D ลำดับ** — กดซ้าย ⟶ ขวา ภายในเวลา (สลักต้องกางพร้อมกัน) | แรมเด้งขึ้นตรง | แรมเอียง ปิ๊บเตือน หมวด `handling` (เหมือนดักดึงเอียงที่มีอยู่) |
| CLEAN (ขาทอง) | ถูยางลบ | **F ถู** — 3 รอบ ความเร็วอยู่ในเขียว | ขาทองวาวเร็วขึ้น | ถูแรงเกิน → คราบเศษยาง ต้องเป่าเพิ่ม |
| **INSTALL** ⭐ | **วางแรมลงสล็อต** | **A จังหวะ** — แรมเลื่อนซ้าย-ขวาเหนือสล็อต กดตอน **ร่องบากตรงสันในสล็อต** | ลงตรงร่อง | ลงผิดร่อง แรมค้าง ปิ๊บ "ร่องไม่ตรงนะ" ลองใหม่ |
| **INSTALL** ⭐ | **กดลงจนสลักดีด** | **B กดค้าง** — ปล่อยตอนได้ยิน "คลิก" (โซนเขียว) | สลักดีดทั้ง 2 ข้าง | ปล่อยเร็ว = ไม่ลงสุด (VERIFY ไม่ผ่าน) · ค้างนานเกิน = สล็อตร้าว −10 |

> ตัวอย่างที่ทีมขอ: "แรมตอนกำลังใส่กลับที่เดิมให้กด" = แถว INSTALL สองแถวบน — ตอนนี้ INSTALL เป็นคลิก 2 ครั้ง จะเปลี่ยนเป็น A ตามด้วย B

### 3.2 Mainboard + CPU

| Phase | จังหวะ | QTE | Perfect / Good | Miss |
|---|---|---|---|---|
| REMOVE | ยกฮีตซิงก์ที่ติดซิลิโคน | **F ถู** แบบหมุน — บิดซ้าย-ขวาเบา ๆ 3 รอบก่อนยก | หลุดสะอาด | บิดแรง/ยกเร็ว → −5 `cpu` เท่ากับเลือก "ดึงตรง ๆ" ในโค้ดตอนนี้ |
| **SEAT_CPU** ⭐ | วาง CPU ลงซ็อกเก็ต | **E มือนิ่ง** — ประคอง CPU ให้สามเหลี่ยมตรงมุม ลดลงช้า ๆ | ลงเรียบ | สั่น/ลงเร็ว → ขางอ (ต้องเปลี่ยนบอร์ด = ของเสีย → `REPAIR_SHOP_SYSTEM.md` 2.4) |
| **PASTE** ⭐ | บีบซิลิโคน | **B กดค้าง** — เม็ดซิลิโคนโตขึ้นตามเวลา ปล่อยตอน "เม็ดถั่ว" | ขนาดพอดี (= ok เดิม) | น้อย (= small) / ล้น (= large) — ผลอุณหภูมิเหมือนเดิม |
| MOUNT | ขันน็อต 4 ตัว | **D ลำดับ** — ไขว้ 1→3→2→4 สองรอบ (รอบแรกหลวม รอบสองแน่น) | กดถูกลำดับ | ไล่รอบ → ฮีตซิงก์เอียง +8°C (เหมือนเดิม) |

### 3.3 GPU + Cable

| Phase | จังหวะ | QTE | Perfect / Good | Miss |

| CLEAN | เป่าใบพัด | **E มือนิ่ง** — ถือใบพัดไว้ (ค้าง) ระหว่างเป่า | ใบพัดไม่หมุน | ปล่อยมือ → ใบพัดหมุนฟรี ปิ๊บเตือน (เหมือนไม่ล็อกใบพัดเดิม) |
| INSTALL | กดการ์ดลงสล็อต | **C วงหด** — กดตอนวงทับ = ได้ยินสลักดีด | สลักล็อก | ลงไม่สุด ต้องกดใหม่ |

### 3.5 BIOS + OS

|---|---|---|---|---|

## 5. คะแนน (เข้ากับระบบเดิม)

- QTE ไม่มีหมวดคะแนนใหม่ — **Miss = `mistake.emit(หมวดเดิม, แต้มเดิม)`** ตามที่แต่ละ Part หักอยู่แล้ว (เช่น RAM ใส่ไม่สุด → หมวด `handling` · Mainboard วาง CPU พลาด → `cpu` · GPU หัวไฟหลวม → `power`)
- **PERFECT ครบทุกครั้งใน Part = ดาวโบนัส** "มือนิ่ง" บนหน้าสรุป (ไม่เพิ่มคะแนน แค่โชว์)
- Miss ซ้ำจุดเดิมหักครั้งเดียว (กันโดนหักรัว) · Miss 3 ครั้ง → ปิ๊บ "ให้ผมช่วยนะ" ทำให้อัตโนมัติ

## 6. โครงโค้ด (ชิ้นส่วนกลางใน PartBase)

```gdscript
# Scripts/MiniGame/PartBase/qte/qte_spec.gd
class_name QteSpec extends Resource

enum Kind { TIMING, HOLD, RING, SEQUENCE, STEADY, RUB }

@export var kind: Kind
@export var duration := 2.0          # วินาที (TIMING: รอบไป-กลับ · RING: เวลาหด · HOLD: เวลาเต็มเกจ)
@export var zone := Vector2(0.45, 0.65)   # ช่วงที่ถือว่าผ่าน (0..1)
@export var perfect := Vector2(0.52, 0.58)
@export var sequence: PackedStringArray = []   # SEQUENCE: ["left","right"] / ["1","3","2","4"]
@export var hint := ""               # ข้อความสั้นบนจอ (ไทย) เช่น "ปล่อยตอนได้ยินคลิก"
@export var sfx_cue := ""            # จุดที่ควรมีเสียง (ไว้ก่อน — ยังไม่มีระบบเสียง)
```

```gdscript
# Scripts/MiniGame/PartBase/qte/qte_runner.gd  — Control ใส่ใน part_base.tscn ชั้นบนสุด
class_name QteRunner extends Control

enum Result { PERFECT, GOOD, MISS }

static var assist := false            # ตั้งค่า "โหมดช่วย": ช้าลง 2 เท่า + โซนกว้าง
static var auto_solve := false        # บอททดสอบ: ผ่าน PERFECT ทันที

## รัน QTE เหนือชิ้นงาน target (Item2D) แล้วคืนผล — ใช้ใน phase: var r = await qte.run(spec, node("RamA1"))
func run(spec: QteSpec, target: Control) -> Result:
	...
```

ใช้ใน phase (ตัวอย่าง RAM INSTALL):

```gdscript
const ALIGN := preload("res://Resources/Qte/ram_align.tres")   # TIMING
const PRESS := preload("res://Resources/Qte/ram_press.tres")   # HOLD

func _install_stick(slot: Item2D) -> void:
	var r: QteRunner.Result = await owner.qte.run(ALIGN, slot)
	if r == QteRunner.Result.MISS:
		say("INSTALL_NOTCH_MISS")
		return                      # ผู้เล่นลองใหม่
	r = await owner.qte.run(PRESS, slot)
	owner.ram_seated = r != QteRunner.Result.MISS
	if not owner.ram_seated:
		mistake.emit(&"handling", 10)
```

- ค่าความยาก (ช่วงโซน · เวลา) อยู่ใน `.tres` ใน `Resources/Qte/` แก้ใน Inspector ได้ ไม่ต้องแตะโค้ด
- ครั้งแรกที่เจอ Part ให้ runner ขยาย `zone` 1.5 เท่าเอง (อ่าน `part_clears` จาก GameState)
- บอททดสอบตั้ง `QteRunner.auto_solve = true` · และควรมีบอทอีกรอบที่ตั้งให้ MISS ทุกครั้ง เพื่อเช็กว่าไม่มีจุดติด

## 8. ลำดับทำ

1. `QteRunner` + แบบ **A จังหวะ** และ **B กดค้าง** (2 แบบนี้ใช้มากสุด)
2. ใส่ใน **RAM INSTALL** ก่อน (ตามที่ทีมยกตัวอย่าง) → ลองเล่นจริงกับคนในทีม ปรับเวลา/โซน
3. **C วงหด** → BIOS กด DEL · GPU INSTALL
4. **E มือนิ่ง** → Mainboard SEAT_CPU · Front Panel CONNECT
5. **D ลำดับ** · **F ถู** → ที่เหลือ
6. โหมดช่วยในหน้าตั้งค่า + บอททดสอบแบบ MISS ทุกครั้ง
