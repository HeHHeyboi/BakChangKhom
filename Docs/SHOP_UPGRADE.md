## 2. ของสิ้นเปลืองแบบเทียร์ (gimmick หลัก)

### 2.1 กติกา

- ของสิ้นเปลืองแต่ละ **ตระกูล** (น้ำยาเช็ด · ซิลิโคน · …) มี **T1 / T2 / T3**
- ซื้อเป็นแพ็ก ได้จำนวนครั้ง · ใช้ในมินิเกม 1 ครั้ง = หัก 1
- เทียร์ต่างกันที่ 4 อย่าง: **ได้ความคืบหน้าต่อครั้ง** · **เวลา** · **โอกาสลูกค้ากลับมาเคลม** · **โบนัสคะแนน**
- ในถาดเครื่องมือแสดงตระกูลละ 1 ไอคอน = เทียร์ที่ตั้งไว้ (ค่าเริ่ม = เทียร์ดีสุดที่มี) + ตัวเลขจำนวนที่เหลือ · กดค้างเพื่อสลับเทียร์
- หมด = ไอคอนเทา · ใช้ T1 ได้เสมอถ้ามี · ไม่มีอะไรเลย = ทำขั้นนั้นไม่ได้ → เก็บงานขึ้นชั้น "รอของ"

### 2.2 รายการ

| ตระกูล | ใช้ใน | T1 (ตลาด · เริ่มเกม) | T2 (ปลดยศช่างฝึกหัด) | T3 (ปลดยศช่างประจำหมู่บ้าน) |
|---|---|---|---|---|

### 2.3 คุ้มไหม — ให้ผู้เล่นคิดได้จากตัวเลขในเกม

1 ช่อง (30 นาที) ของงาน Lv3 ≈ **฿90** (฿450 ÷ 5 ช่อง) · เคลม 1 ครั้ง = ซ่อมฟรีอีก ~2 ช่อง (≈ ฿180) + ชื่อเสียง −

ตัวอย่าง: งาน Mainboard 1 งาน (เช็ด 1 + ซิลิโคน 1)

| ใช้ | ค่าของ | เวลาเพิ่ม/ลด | เคลม (คาดหวัง) | รวม "ต้นทุนจริง" |
|---|---|---|---|---|
| T1 + T1 | ฿18 | +30 นาที (≈ ฿45) | 20% × ฿180 = ฿36 | **~฿99** |
| T2 + T2 | ฿45 | 0 | 5% × ฿180 = ฿9 | **~฿54** |
| T3 + T3 | ฿105 | −15 นาที (≈ −฿23) | 0 | **~฿82** − บริการ +3 (โอกาส ⭐⭐⭐ = ทิป) |

→ **T2 คุ้มสุดสำหรับงานทั่วไป** · T3 คุ้มเมื่อเวลาแน่น (เส้นตาย · งานล้นกระดาน) หรือไล่ ⭐⭐⭐ · T1 พอใช้ตอนเงินช็อต
ไม่มีเทียร์ไหนดีสุดเสมอ = **มีการตัดสินใจ**

สมุดช่าง (GAME_REDESIGN 11.2) มีหน้า "ต้นทุนต่องาน" แสดงตารางนี้หลังผู้เล่นใช้ครบทุกเทียร์ของตระกูลนั้น

## 5. เครื่องราง (Talisman) — "หิ้งของนำโชคหน้าร้าน"

### 5.1 กติกา

- หิ้งหน้าร้านมี **2 ช่อง** (อัปเกรดเป็น 3 · 4) · วาง/สลับได้ **ตอนเปิดร้าน 08:30 เท่านั้น** (ต้องวางแผนก่อนเริ่มกะ)
- ชิ้นเดียวกันวางซ้ำไม่ได้ · ผลเล็ก ๆ (5–20%) ไม่ทำให้เกมง่ายเกิน
- บางชิ้นมี **ข้อแลก** ให้คิดว่าคุ้มไหม
- ได้จาก: รถพุ่มพวง (สุ่มซื้อ) · ลูกค้าให้เป็นของขวัญเมื่อได้ ⭐⭐⭐ (โอกาส 10%) · เหตุการณ์ (งานบุญบั้งไฟ · ปีใหม่) · เนื้อเรื่อง
- ขายคืนได้ครึ่งราคา (ยกเว้นของจากเนื้อเรื่อง)
- **กรอบการนำเสนอ:** เป็น "ของนำโชค/ของที่ระลึก" ที่ทำให้ขมมั่นใจและลูกค้าเอ็นดู — คำอธิบายผลใช้เหตุผลทางโลก (เช่น "ลูกค้าเห็นแมวกวักแล้วอารมณ์ดี") · **ไม่ใช้พระเครื่อง/วัตถุมงคลทางศาสนาจริง** (ดูข้อ 9 #4)

## 7. โค้ด

### 7.1 ของสิ้นเปลือง — ต่อยอด `ToolDef` ที่มีแล้ว

`ToolDef` มี `uses` · `price` · `unlock_rank` อยู่แล้ว → เพิ่มช่องเทียร์ ไม่ต้องสร้าง class ใหม่

```gdscript
# Scripts/Resources/tool_def.gd (เพิ่ม)
@export_group("ของสิ้นเปลือง")
@export var family: StringName          # &"wipe" · &"paste" · &"contact" · &"air" · &"tie" · &"cmos" · &"av"
@export_range(1, 3) var tier := 1
@export var pack_uses := 0              # 0 = เครื่องมือ (ไม่หมด)
@export var gain_mult := 1.0            # ×ความคืบหน้าต่อครั้ง
@export var minutes_delta := 0          # +30 = ต้องรอแห้ง · −15 = เร็วขึ้น
@export_range(0.0, 1.0) var claim_risk := 0.0
@export var score_bonus := 0            # คะแนนบริการ/วิธีทำ
```

ไฟล์ `.tres` ใหม่ใน `Resources/Tool/`: `wipe_t1_alcohol70` · `wipe_t2_ipa90` · `wipe_t3_ipa99` · `paste_t1_white` · `paste_t2_grey` · `paste_t3_premium` · `contact_t2_spray` · `air_t2_can` · `tie_t1` · `tie_t2_velcro` · `cmos_t1` · `cmos_t2` · `av_t1_free` · `av_t2_license` (แก้บั๊ก LEVEL_DESIGN 0.2 #2 ไปในตัว — Mainboard ได้เครื่องมือ WIPE)

ใน `phase_clean.gd` ทั้ง 3 Part: `_progress_by(gain * tool.gain_mult)` · `TimeSystem.advance_minutes(tool.time_minutes + tool.minutes_delta)` · หัก `GameState.use_stock(tool.id)` · เก็บ `claim_risk` สูงสุดของงานลง `WorkOrder` → ส่งมอบแล้วสุ่มเคลม

### 7.2 Resource ใหม่

# Scripts/Resources/shop_upgrade_def.gd
class_name ShopUpgradeDef extends Resource

@export var random_picks := 0           # รถพุ่มพวง = 4

### 7.3 ตัวรวมโบนัสที่เดียว — ทุกระบบถามจากตรงนี้

```gdscript
# GameState (เพิ่ม)
var stock: Dictionary[StringName, int] = {}        # tool_id → ครั้งที่เหลือ
var upgrades: Dictionary[StringName, int] = {}     # upgrade_id → เทียร์
var charms_owned: Array[StringName] = []
var charms_equipped: Array[StringName] = []        # ≤ shelf slots
var piggy_bank := 0

## รวมค่าจากอัปเกรด + เครื่องรางที่วางอยู่ · คีย์ที่ไม่มี = default
func mod(key: StringName, default := 0.0) -> float: ...
```

ใช้: `DayLoop` (`walkin_bonus` · `board_bonus`) · `QteRunner` (`qte_zone_mult`) · `PibHint` (`hint_bonus`) · หน้าส่งมอบ (`tip_3star` · `claim_mult` · `patience_bonus`) · TimeSystem (`ot_free` · `ot_no_oversleep`) — ไม่ต้องเขียน if ตามชื่อเครื่องรางกระจายทั่วโค้ด

> ทั้งหมดต้องเข้า Save (`stock` · `upgrades` · `charms_*` · `piggy_bank` · ของที่สั่งยังไม่มาถึง)

### 7.4 ลำดับทำ (เสนอ)

1. `ToolDef` ช่องเทียร์ + `.tres` ตระกูลน้ำยาเช็ด/ซิลิโคน 6 ไฟล์ + หัก stock ใน Mainboard (แก้บั๊ก WIPE ไปด้วย) — **เห็น gimmick ได้เร็วสุด**
2. `GameState.mod()` + `stock`
3. ร้านในตลาด (ฉาก Market ที่มี + หน้าต่างร้าน) · ร้านออนไลน์ในขมOS (หลังทำขมOS ตาม LEVEL_DESIGN)
4. อัปเกรดร้าน 4 ชิ้นแรก: ชั้นวาง · ป้ายไวนิล · โคมแว่นขยาย · ไฟหน้าร้าน
5. หิ้งเครื่องราง + 6 ชิ้นธรรมดา + รถพุ่มพวง
6. เคลม (ต้องมีระบบงานกลับมา) · ชิ้นที่เหลือ · ของจากเนื้อเรื่อง
