## 1. ความรู้ที่ Part นี้สอน

| หัวข้อ | สิ่งที่ผู้เล่นต้องเข้าใจหลังเล่นจบ |
|---|---|
| PCIe x16 | สลอตยาวสุดใกล้ CPU คือช่องของการ์ดจอ · มีสลักล็อกปลายสลอต |
| สลักล็อก | ต้องกดสลักก่อนดึงการ์ด ไม่งั้นสลอตแตก |
| สายไฟ PCIe vs CPU | หัว 8-pin สองแบบหน้าตาคล้ายกันแต่ **เสียบสลับกันไม่ได้** ต้องดูตัวหนังสือบนหัว |
| การ์ดหย่อน (GPU sag) | การ์ดหนักทำให้สลอตงอเมื่อเวลาผ่านไป ต้องมีตัวค้ำ |
| Airflow | ลมเข้าหน้า–ล่าง ออกหลัง–บน · สายรกขวางทางลม |
| Cable management | จัดสายไม่ใช่เรื่องสวยงามอย่างเดียว แต่คือเรื่องอุณหภูมิและการซ่อมครั้งหน้า |

**เคสลูกค้า:** C03 "ไฟติด พัดลมหมุน แต่จอไม่ขึ้น"
คำสำคัญ: ไม่มีเสียงบี๊บ · เพิ่งเสียบการ์ดจอใหม่ · จอขึ้นถ้าเสียบสายที่เมนบอร์ด

## 2. Flow 8 Phase

```
0 INSPECT      สังเกต — เสียบสาย HDMI ที่เมนบอร์ดแล้วภาพขึ้น = การ์ดจอไม่ทำงาน
1 BRIEFING     ปิ๊บสอน: PCIe คืออะไร ทำไมต้องต่อไฟเพิ่ม
2 SAFETY       ตัดไฟ + ESD
3 REMOVE       ถอดสายไฟการ์ด → ไขน็อตยึดท้ายเคส → กดสลัก → ดึงการ์ดขึ้นตรง ๆ
4 CLEAN        เป่าฝุ่นพัดลม/ครีบ + ขัดขาทอง PCIe  ← เลือกอุปกรณ์
5 INSTALL      วางการ์ดลงสลอต กดจนสลักดีด → ขันน็อตท้ายเคส
6 POWER        เลือกสายไฟให้ถูกเส้น แล้วเสียบ  ← จุดตัดสินของ Part นี้
7 AIRFLOW      จัดสายและตั้งทิศพัดลม → VERIFY → SUMMARY
```

**เวลาเล่น:** รอบแรก 5–6 นาที · รอบซ้ำ 2 นาที

## 4. Phase 4 · CLEAN — เลือกอุปกรณ์

**งานย่อย 3 ขั้น:** S1 ฝุ่นบนใบพัดลม · S2 ฝุ่นในครีบระบายความร้อน · S3 ขาทอง PCIe

| อุปกรณ์ | S1 ใบพัด | S2 ครีบ | S3 ขาทอง |
|---|:--:|:--:|:--:|
| แปรงขนนุ่มกันไฟฟ้าสถิต | ✅ | 🟡 | 🟡 |
| ลูกยางเป่าลม | ✅ | ✅ | ❌ |
| ยางลบสีขาว | ❌ | ❌ | ✅ |
| คอตตอนบัด + IPA 99% | 🟡 | ❌ | ✅ |
| ผ้าไมโครไฟเบอร์แห้ง | 🟡 | ❌ | 🟡 |
| ไดร์เป่าผม / ปืนลมร้อน | ❌ | ❌ | ❌ |
| เครื่องดูดฝุ่นบ้าน | ❌ | ❌ | ❌ |

**กติกาพิเศษของ Part นี้ — ต้องล็อกใบพัดก่อนเป่า**

| การกระทำ | ผล |
|---|---|
| ใช้นิ้ว/ไม้จิ้มฟันล็อกใบพัดแล้วเป่า | ✅ |
| เป่าเลยโดยไม่ล็อก | 🟡 ใบพัดหมุนฟรีเร็วจัด → ปิ๊บอธิบายว่าพัดลมกลายเป็นเครื่องปั่นไฟ ทำแบริ่งและวงจรพัง −5 |

## 5. Phase 6 · POWER — จุดตัดสินของ Part นี้

ถาดมีหัวสาย 4 แบบ ผู้เล่นต้องลากเส้นที่ถูกไปเสียบเข้าการ์ด

| หัวสาย | ผล |
|---|---|
| **PCIe 8-pin (6+2)** | ✅ ถูกต้อง — แยกออกเป็น 6+2 ได้ มีตัวหนังสือ `PCI-E` บนหัว |
| CPU 8-pin (EPS) | ❌ หน้าตาคล้ายมาก แต่ร่องกันผิดคนละแบบ — ปิ๊บห้ามทันครั้งแรก · ครั้งที่สอง = ฝืนเสียบ ไฟลัดวงจร **การ์ดจอพัง ต้องซื้อใหม่** |
| SATA power | ❌ หัวแบนคนละแบบ เสียบไม่เข้าอยู่แล้ว (ปิ๊บใช้สอนว่าผู้ผลิตออกแบบกันผิดไว้แล้ว) |
| Molex 4-pin เก่า | 🟡 ใช้หัวแปลงได้แต่ไม่แนะนำ กระแสไม่พอ — ผ่านแบบมีคำเตือน |

**เช็กเพิ่ม:** เสียบแล้วต้องได้ยินเสียง *คลิก* จากสลักบนหัวสาย ถ้าผู้เล่นกด "ต่อไป" ทั้งที่ยังไม่คลิก → ตอน VERIFY เครื่องจะดับกลางคัน ให้ย้อนกลับมาแก้

## 6. Phase 7 · AIRFLOW — จัดสายและทิศลม

### 6.1 จัดสาย

ลากสาย 3 เส้นไปเข้าช่องหลังถาดเมนบอร์ด แล้วรัดเคเบิลไท

| ผลลัพธ์ | คะแนน |
|---|---|
| สายเก็บหลังถาดครบ 3 เส้น + รัดไท | ✅ เต็ม |
| เก็บบางเส้น | 🟡 −3 |
| ปล่อยสายพาดหน้าพัดลม | ❌ −8 และตอน VERIFY มีเสียงใบพัดตีสาย |

### 6.2 ตั้งทิศพัดลม (ลากลูกศร)

| ตำแหน่ง | ทิศที่ถูก |
|---|---|
| พัดลมหน้าเคส | **เป่าเข้า** (intake) |
| พัดลมหลังเคส | **เป่าออก** (exhaust) |
| พัดลมบน | เป่าออก (ลมร้อนลอยขึ้น) |

ตั้งผิดทิศ → ตอน VERIFY อุณหภูมิสูงกว่าปกติ + ปิ๊บอธิบายเรื่องลมร้อนวนในเคส

## 7. บทปิ๊บ (`Assets/Dialog/MiniGame/Gpu_Pib.txt`)

```

ปิ๊บ,สลอตยาวที่สุดบนเมนบอร์ดที่อยู่ใกล้ CPU นั่นแหละคือ PCIe x16 ช่องของการ์ดจอ
ปิ๊บ,การ์ดจอกินไฟเยอะกว่าที่สลอตจ่ายให้ได้ เลยต้องต่อสายไฟจากพาวเวอร์เพิ่มอีกเส้น
ปิ๊บ,เครื่องนี้จอไม่ขึ้นเพราะลืมต่อสายเส้นนั้น ไม่ใช่การ์ดเสียนะ

# Phase 3 ถอดการ์ด
ปิ๊บ,ปลายสลอตมีสลักพลาสติกอยู่ ต้องกดลงก่อนถึงจะดึงการ์ดขึ้นได้
ปิ๊บ,ถ้าดึงทั้งที่สลักยังล็อก สลอตแตกเลยนะ แล้วเมนบอร์ดทั้งแผ่นก็จบ

# Phase 4 ทำความสะอาด
ปิ๊บ,ก่อนเป่าฝุ่นให้ใช้นิ้วล็อกใบพัดไว้ก่อน
ปิ๊บ,ถ้าปล่อยให้มันหมุนฟรีด้วยแรงลม พัดลมจะกลายเป็นเครื่องปั่นไฟเล็ก ๆ ส่งไฟย้อนกลับเข้าวงจร

# Phase 6 เลือกสายไฟ — ตอบถูก
ปิ๊บ,ใช่ ดูตรงหัวสิ มันเขียนว่า PCI-E แล้วแยกออกเป็น 6 กับ 2 ได้ด้วย
ปิ๊บ,หัว CPU 8-pin หน้าตาเหมือนกันเป๊ะ แต่ร่องกันผิดคนละแบบ เสียบสลับกันคือการ์ดพัง

# เลือกหัว CPU 8-pin
ปิ๊บ,เดี๋ยว! หัวนั้นเป็นของ CPU นะ มันจ่ายไฟคนละแบบ
ปิ๊บ,ถ้าฝืนเสียบเข้าไป ไฟจะวิ่งผิดขา การ์ดจอไหม้ทันที ของจริงคือหลักหมื่นเลยนะขม

# Phase 7 airflow
ปิ๊บ,ลมเย็นเข้าทางหน้ากับด้านล่าง ลมร้อนออกทางหลังกับด้านบน จำง่าย ๆ ว่าลมร้อนลอยขึ้น
ปิ๊บ,ถ้าตั้งพัดลมหลังให้เป่าเข้า ลมร้อนจะวนอยู่ในเคสไม่ออกไปไหน
ปิ๊บ,เก็บสายให้เรียบร้อยด้วยนะ ไม่ใช่แค่ให้สวย แต่สายที่พาดขวางคือกำแพงกันลม

# SUMMARY
ปิ๊บ,จบงานแล้ว ภาพขึ้นสวยเลย
ปิ๊บ,จำสามอย่างนี้ไว้ — กดสลักก่อนดึง ดูตัวหนังสือบนหัวสายก่อนเสียบ และลมต้องมีทางเข้าทางออก
```

## 10. สเปกโค้ด

```gdscript
# Scripts/MiniGame/PartGpu/part_gpu.gd
class_name PartGpuGame extends PartMinigameBase

enum Phase { INSPECT, BRIEFING, SAFETY, REMOVE, CLEAN, INSTALL, POWER, AIRFLOW }
enum CleanStep { FAN_BLADES, HEATSINK_FINS, GOLD_CONTACTS }
enum CableType { PCIE_8PIN, CPU_8PIN, SATA, MOLEX }
enum FanDir { INTAKE, EXHAUST }

var clip_released := false
var cable_locked := false          # ได้ยินเสียงคลิกหรือยัง
var fan_dirs := {"front": FanDir.INTAKE, "rear": FanDir.EXHAUST, "top": FanDir.EXHAUST}
```

* สายไฟแต่ละแบบเป็น Resource `CableDef` (`id`, `label_on_head`, `fits: bool`, `damage_on_force: bool`)
* การถอดตรวจ `clip_released` ก่อนอนุญาต drag — เหมือน `clip` ของ Part RAM ใช้โครงเดียวกันได้
* คะแนน airflow คำนวณจาก `fan_dirs` เทียบกับค่าที่ถูก + จำนวนสายที่เก็บ
