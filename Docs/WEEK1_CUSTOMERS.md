เหตุผลของแต่ละคนต่อกันเป็นเรื่อง: ยาย → ลุงอำนวย → ผู้ใหญ่บ้าน · ร้านในเมืองไกล → เด็ก · ผอ. → ครู → ผอ. · ป้ายร้าน → เด็กหญิง · ลูกค้าเก่ากลับมา → ลุงอำนวย = ร้านเริ่มมีชื่อเสียงตลอด 7 วัน

### Event บังคับ (วันที่ 1)
- เกิดทันทีหลังเควสต์หลักจบ (Tutorial ประกอบคอม + ซ่อมแรมคอมตัวเอง) และขมอยู่ในบ้าน/ห้อง
- **พักก่อน (ครั้งเดียวต่อเกม):** บท `Assets/Dialog/Break/after_tutorial.txt` (ปิ๊บชม · ยายเรียกกินขนม) → จอมืดครึ่งหนึ่ง นาฬิกาหมุน 08:00 → 08:30 ใน 1 วิ (`DayLoop.break_dialog` · `break_minutes` · `time_skip_seconds` แก้ใน Inspector ของ `Scene/Core/day_loop.tscn`)
- อยู่ในร้านครบ `forced_delay` (0.8 วิ) → ลุงอำนวยเดินเข้ามาเอง (บทเล่นอัตโนมัติ ไม่มีการ์ดให้กด) · ปิ๊บบอกว่าเป็นอาการที่เพิ่งฝึก
- จบบท → การ์ด **"งานด่วน!"** มีปุ่ม "เริ่มซ่อม" ปุ่มเดียว (ปฏิเสธ/ปิดร้านไม่ได้) → มินิเกม RAM → การ์ดผลงาน
- งานแรม **ในเควสต์** (คอมของขมเอง) ไม่คิดเงิน · เงินเริ่มนับจากลุงอำนวย

## 3. แก้ใน Inspector

### 3.1 แก้ลูกค้า 1 คน
ดับเบิลคลิก `Resources/Customers/w1_d1_amnuay_ram.tres` → Inspector:

| กลุ่ม | ช่อง | ใส่อะไร |
|---|---|---|
| ลูกค้า | `id` | รหัสไม่ซ้ำ เช่น `w1_d1_amnuay` |
| | `customer` | ชื่อตัวละคร **ต้องตรง key ใน `Scene/Global.tscn` `_CharacterMap`** (ขม · ยาย · ปิ๊บ · มิ้น · ผู้ใหญ่บ้าน · ครู · ลุงอำนวย · ผอ. · เด็ก · เด็กหญิง …) |
| | `reason` | **บังคับ** เหตุผลที่มาร้าน — โชว์บนการ์ด "มาเพราะ: …" |
| | `device` | เครื่องของลูกค้า |
| | `symptom` | อาการที่ลูกค้าเล่า |
| งานซ่อม | `part_id` | dropdown 5 Part → เปิดมินิเกมตัวนั้น |
| | `job_title` | ชื่องานบนการ์ด |
| | `fee` | ค่าซ่อม · `-1` = ใช้ค่าจาก `economy.tres` |
| | `scene_override` | มินิเกมอื่นแทน (ปกติเว้นว่าง) |
| บทพูด | `arrive_dialog` | ไฟล์ `.txt` บทตอนเข้าร้าน |
| | `bg` | ฉากหลังของบท |
| | `thanks_text` / `complain_text` | ลูกค้าพูดตอนรับเครื่อง ถ้าซ่อมผ่าน / ไม่ผ่าน (โชว์บนการ์ดผลงาน) |
| Event | `forced` | ✔ = event บังคับ (บทเล่นเอง · ปฏิเสธไม่ได้) |

### 3.2 สลับวัน / เพิ่มลูกค้า
1. ดับเบิลคลิก `Resources/Week/week1.tres`
2. `days` → ลากไฟล์ `.tres` จาก FileSystem ใส่ช่อง 0–6 (ช่อง 0 = วันที่ 1)
3. ช่องที่เป็น `<empty>` = วันนั้นสุ่มจาก `random_pool`

ลูกค้าใหม่: คลิกขวา `Resources/Customers/` → **New Resource… → CustomerCase** → กรอก → ลากใส่ `days` หรือ `random_pool`

### 3.3 เพิ่ม Week 2+
New Resource → **WeekPlan** → ตั้ง `week = 2` → ใส่ `days` → เปิด `Scene/Core/day_loop.tscn` → เพิ่มใน `week_plans` · รอบที่ไม่มีแผน = สุ่มทุกวัน

## 4. เขียนบทลูกค้า (`Assets/Dialog/Customer/*.txt`)

```
# คอมเมนต์ขึ้นต้นด้วย #
ลุงอำนวย,คอมเครื่องนี้ลุงใช้มาหกปีแล้ว ไม่เคยเปิดฝาเลยสักครั้ง
ขม (ตกใจ),ลุงอำนวย! ร้านยังไม่ทันเปิดเลยครับ
ปิ๊บ (ยิ้ม),ลูกค้าคนแรกของร้านเลยนะขม!
```

- อารมณ์เขียนในวงเล็บหลังชื่อ: `(ยิ้ม)` `(ดีใจ)` → happy · `(กังวล)` `(ตกใจ)` `(เหนื่อย)` → worry
- ⚠ **ห้ามใช้ `:` ในบรรทัด** — `DialogScene` อ่าน `:` เป็นหัว branch ของ `Choice:` บรรทัดที่เหลือจะหายหมด (`CustomerCase.problems()` เตือนให้แล้ว)
