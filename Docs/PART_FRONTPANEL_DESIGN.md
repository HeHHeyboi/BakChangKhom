## 1. ความรู้ที่ Part นี้สอน

| หัวข้อ | สิ่งที่ผู้เล่นต้องเข้าใจหลังเล่นจบ |
|---|---|
| Pin header | แผงพินเล็ก ๆ มุมล่างขวาเมนบอร์ด คือทางที่ปุ่มหน้าเคสสั่งงานเครื่อง |
| อ่านผังจากเมนบอร์ด | ตัวหนังสือจิ๋วข้างพินบอกว่าอันไหนคืออะไร — ต้องส่องไฟดู ไม่ใช่เดา |
| สวิตช์ไม่มีขั้ว | POWER SW / RESET SW เสียบกลับด้านได้ เพราะเป็นแค่สวิตช์ปิด-เปิดวงจร |
| LED มีขั้ว | POWER LED / HDD LED กลับด้านแล้วไฟไม่ติด (แต่ไม่พัง) |
| Dual channel | แรม 2 แถวต้องอยู่สลอตสีเดียวกัน (A2 + B2) ถึงจะวิ่งคู่กัน เร็วขึ้นจริง |
| ทำไมไม่ใช่ A1+A2 | สองแถวในช่องเดียวกันคือ single channel — ช้ากว่าแต่ยังใช้ได้ |

**เคสลูกค้า:** C02 "กดปุ่มแล้วเครื่องไม่ติดเลย"
คำสำคัญ: ไฟเขียวบนเมนบอร์ดยังติด · เพิ่งทำความสะอาดเครื่องเอง · ตัวลวง = "สงสัยพาวเวอร์เสีย"

## 2. Flow 8 Phase

```
0 INSPECT      ไฟเมนบอร์ดติด = ไฟมาถึงแล้ว แต่กดปุ่มไม่ติด → ปัญหาอยู่ที่สวิตช์หน้าเคส
1 BRIEFING     ปิ๊บสอน: ปุ่ม power จริง ๆ แค่ต่อวงจร 2 ขาให้ถึงกัน
2 SAFETY       ตัดไฟ + ESD + หยิบไฟฉาย
3 READ_MAP     ส่องไฟอ่านผังพินบนเมนบอร์ด → ปลดล็อกหน้าจอผังในเกม
4 CONNECT      เสียบหัวต่อ 4 หัวให้ถูกตำแหน่งและถูกขั้ว  ← หัวใจของ Part
5 TEST_BUTTON  เสียบไฟ กดปุ่มหน้าเคส ดูว่าเครื่องติดและไฟ LED ติด
6 DUAL_CHANNEL จัดแรม 2 แถวลงสลอตให้เป็น dual channel
7 VERIFY       บูตเข้า BIOS ดูว่าขึ้น Dual Channel → SUMMARY
```

**เวลาเล่น:** รอบแรก 6–8 นาที (Phase 4 กินเวลาที่สุด) · รอบซ้ำ 2–3 นาที

## 3. Phase 3 · READ_MAP — ต้องอ่านก่อนเสียบ

ผู้เล่นลาก **ไฟฉาย** ไปส่องที่แผงพิน → ภาพซูมขึ้นมาให้เห็นตัวหนังสือข้างพิน

| ถ้าข้ามขั้นนี้ | ผล |
|---|---|
| เสียบเลยโดยไม่ส่อง | เล่นได้ แต่ **ผังจะถูกซ่อน** ต้องเดาตำแหน่งเอง และหักคะแนน −10 |
| ส่องแล้ว | ผังโผล่ค้างไว้มุมจอตลอด Phase 4 |

> ออกแบบให้ "การอ่านคู่มือ" เป็นการกระทำในเกม ไม่ใช่ข้อความที่ผู้เล่นข้ามได้

---

## 4. Phase 4 · CONNECT — เสียบหัวต่อ 4 หัว

แผงพินมี 9 ตำแหน่ง (2 แถว) ผู้เล่นลากหัวต่อไปวาง

| หัวต่อ | มีขั้ว? | เสียบผิดตำแหน่ง | เสียบกลับขั้ว |
|---|---|---|---|
| POWER SW | ไม่มี | เครื่องไม่ติด | ✅ ใช้ได้ปกติ |
| RESET SW | ไม่มี | กดรีเซ็ตแล้วเครื่องดับ/ไม่ทำงาน | ✅ ใช้ได้ปกติ |
| POWER LED | **มี** | ไฟไม่ติด | ❌ ไฟไม่ติด (ไม่พัง) |
| HDD LED | **มี** | ไฟไม่กะพริบ | ❌ ไฟไม่กะพริบ |

**กติกา**

* เสียบผิด **ไม่มีอะไรพัง** — Part นี้สอนเรื่องความละเอียด ไม่ใช่ความกลัว
* ความผิดพลาดจะไปโผล่ตอน Phase 5 (กดปุ่มแล้วไม่ติด / ไฟไม่ขึ้น) ให้ผู้เล่นย้อนกลับมาแก้เอง
* ปิ๊บจะไม่บอกคำตอบตรง ๆ แต่ชี้ทางว่า "ลองดูว่าไฟดวงไหนไม่ติด แล้วย้อนไปดูหัวนั้น"

**ตารางวินิจฉัยที่ผู้เล่นควรสรุปได้เอง (โชว์ในหน้าสรุป)**

| อาการ | สาเหตุ |
|---|---|
| กดปุ่มแล้วเงียบสนิท | POWER SW ผิดตำแหน่ง |
| เครื่องติดแต่ไฟหน้าเคสไม่ติด | POWER LED กลับขั้ว |
| ไฟติดแต่ไม่กะพริบตอนอ่านข้อมูล | HDD LED ผิดตำแหน่ง/กลับขั้ว |
| กดรีเซ็ตแล้วเครื่องดับเลย | สลับ RESET กับ POWER SW |

---

## 5. Phase 6 · DUAL_CHANNEL — จัดแรม 2 แถว

สลอต 4 ช่อง: **A1 A2 B1 B2** (A1/B1 สีหนึ่ง · A2/B2 อีกสีหนึ่ง)

| การจัด | ผล |
|---|---|
| **A2 + B2** (สีเดียวกัน คนละแชนแนล) | ✅ Dual channel — คู่มือเมนบอร์ดส่วนใหญ่แนะนำคู่นี้ |
| A1 + B1 | ✅ Dual channel เหมือนกัน แต่ปิ๊บบอกว่าคู่มือแนะนำ A2+B2 เพราะเว้นที่ให้ฮีตซิงก์ CPU |
| A1 + A2 | 🟡 Single channel — เครื่องใช้ได้ แต่แบนด์วิดท์ครึ่งเดียว −8 |
| B1 + B2 | 🟡 เหมือนข้างบน |
| เสียบแถวเดียว | 🟡 ผ่านแต่เป็น single channel −8 |
| เสียบไม่ลงล็อก (สลักไม่ดีด) | ❌ Phase 7 บูตไม่ผ่าน ต้องกลับมาแก้ |

**Verify:** หน้าจอ BIOS ขึ้นข้อความ `Memory: 16GB  Dual Channel` หรือ `Single Channel` ตามที่จัดจริง

## 6. บทปิ๊บ (`Assets/Dialog/MiniGame/FrontPanel_Pib.txt`)

```
# Phase 1 BRIEFING
ปิ๊บ,ขมรู้มั้ยว่าปุ่ม power หน้าเคสจริง ๆ แล้วไม่ได้มีไฟวิ่งผ่านเลย
ปิ๊บ,มันแค่เอาขาสองขาบนเมนบอร์ดมาแตะกันชั่วขณะ เมนบอร์ดเห็นว่าแตะกันก็สั่งเปิดเครื่อง
ปิ๊บ,เครื่องนี้ไฟเขียวบนเมนบอร์ดยังติด แปลว่าไฟมาถึงแล้ว ปัญหาอยู่ที่สายจากปุ่มหน้าเคส

# Phase 3 อ่านผัง
ปิ๊บ,ก่อนเสียบอะไร หยิบไฟฉายส่องดูตัวหนังสือข้างแผงพินก่อนนะ
ปิ๊บ,ตัวเล็กมากแต่มันบอกครบเลยว่าขาไหนคืออะไร ช่างที่เดาคือช่างที่ต้องรื้อซ้ำ

# Phase 4 เสียบหัวต่อ
ปิ๊บ,สวิตช์สองอันแรก POWER SW กับ RESET SW เสียบกลับด้านได้ ไม่เป็นไร เพราะมันแค่สวิตช์
ปิ๊บ,แต่พวก LED มีขั้วบวกลบนะ กลับด้านแล้วไฟไม่ติด แต่ไม่พังหรอก ไม่ต้องกลัว
ปิ๊บ,สายขั้วบวกมักเป็นสีอ่อนหรือมีลูกศรเล็ก ๆ ที่หัว ส่วนขั้วลบเป็นสีขาวหรือดำ

# Phase 5 กดปุ่มแล้วไม่ติด
ปิ๊บ,ไม่ติดเหรอ ไม่ต้องตกใจ ลองคิดย้อนกลับ — ถ้าไฟเมนบอร์ดติดแต่กดปุ่มแล้วเงียบ
ปิ๊บ,แปลว่าสัญญาณจากปุ่มไปไม่ถึง ลองดูว่าหัว POWER SW เสียบตรงคู่ที่ผังบอกมั้ย

# Phase 6 dual channel
ปิ๊บ,สลอตแรมสี่ช่องนี้แบ่งเป็นสองแชนแนล สังเกตจากสีสลอตได้เลย
ปิ๊บ,ถ้าอยากให้แรมวิ่งคู่กัน ต้องเสียบสองแถวลงสลอตสีเดียวกัน คนละแชนแนล
ปิ๊บ,เสียบติดกันสองช่องแรกก็ใช้ได้นะ แต่ความเร็วเหลือครึ่งเดียว เสียของเปล่า ๆ

# SUMMARY
ปิ๊บ,เสร็จแล้ว ปุ่มกดติด ไฟหน้าเคสสว่าง แรมก็วิ่ง dual channel
ปิ๊บ,งานนี้ไม่มีอะไรพังได้เลย มีแต่ติดกับไม่ติด สิ่งที่ต้องใช้คือความละเอียด ไม่ใช่ความกล้า
```

## 9. สเปกโค้ด

```gdscript
# Scripts/MiniGame/PartFrontPanel/part_front_panel.gd
class_name PartFrontPanelGame extends PartMinigameBase

enum Phase { INSPECT, BRIEFING, SAFETY, READ_MAP, CONNECT, TEST_BUTTON, DUAL_CHANNEL, VERIFY }
enum PinSlot { PWR_SW_A, PWR_SW_B, RST_SW_A, RST_SW_B, PWR_LED_P, PWR_LED_N, HDD_LED_P, HDD_LED_N, NC }
enum RamSlot { A1, A2, B1, B2 }

var map_revealed := false
var pin_placement: Dictionary = {}     # connector_id -> PinSlot
var ram_placement: Array[RamSlot] = []

func is_dual_channel() -> bool:
	if ram_placement.size() != 2: return false
	var a = ram_placement[0] in [RamSlot.A1, RamSlot.A2]
	var b = ram_placement[1] in [RamSlot.B1, RamSlot.B2]
	return a != b      # ต้องคนละแชนแนล
```

* หัวต่อแต่ละอันเป็น Resource `PanelConnector` (`id`, `has_polarity`, `correct_slot`, `line_wrong_slot`, `line_wrong_polarity`)
* Phase 5 ไม่บอกคำตอบ — ใช้ `_diagnose()` แปลงสถานะการเสียบเป็น "อาการ" แล้วให้ปิ๊บพูดอาการนั้น
* ใช้ `PibHint.point_at()` ชี้ไปที่ LED ที่ไม่ติด แทนการบอกว่าเสียบผิดหัวไหน
