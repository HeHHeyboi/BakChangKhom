## 1. หลักคิด — ทำไมเริ่มจาก "ลงโปรแกรม ลบไฟล์"

คนที่ไม่เคยซ่อมคอมไม่ได้กลัวไขควง แต่ **ไม่รู้ว่าปัญหาส่วนใหญ่ไม่ต้องเปิดเครื่องเลย** · ช่างจริงไล่จากง่ายไปยากเสมอ: ดูจอ → ดูสาย → ดูโปรแกรม → ค่อยเปิดเคส → ค่อยวัดไฟ (ตรงกับกรอบ O.I.T.F.V.)

```
Lv1 ง่าย      บนหน้าจอ             เมาส์อย่างเดียว      "ใช้คอมเป็น"
Lv2 ปกติ      นอกเคส + เปิดฝาแรก     + ไขควง แปรง         "ดูแลเครื่องเป็น"
Lv3 ปานกลาง   ในเคส ทำความสะอาด     + IPA ซิลิโคน         "ล้างเครื่องเป็น"
Lv4 ยาก       วินิจฉัย + เปลี่ยนชิ้น    + เครื่องมือวัด        "หาจุดเสียเป็น"
Lv5 ชำนาญ     ระบบทั้งเครื่อง          + USB บูต · งบลูกค้า   "จัดการทั้งเครื่องเป็น"
```

กติการ่วม 3 ข้อ
1. **ระดับเดียวกัน = ทักษะใหม่อย่างเดียว** — ไม่ให้เจอของใหม่ 2 อย่างพร้อมกัน
2. **งานง่ายไม่หายไป** — Lv1 ใช้เวลา 1–2 ช่อง เป็นงานเติมช่องว่างก่อนพักเที่ยง/ก่อนปิดร้านตลอดเกม
3. **ระดับสูงใช้ทักษะระดับต่ำ** — งาน Lv4 อาจจบที่ "ปิดโปรแกรมเปิดพร้อมเครื่อง" (Lv1) ถ้าผู้เล่นไล่ตรวจถูกลำดับ

## 5. คำนวณจำนวนงานต่อเดือน

### 5.1 สูตร

```
ชั่วโมงงานต่อเดือน     = 16 ช่อง × 20 กะ = 320 ช่อง (160 ชม.)
ช่องที่ใช้ซ่อมจริง      = 320 × อัตราใช้เวลา (เผื่อพลาด · เดินทาง · ไปตลาดนอกเวลาพัก)
ช่องเฉลี่ยต่องาน        = Σ (สัดส่วนระดับ × ช่องเฉลี่ยของระดับ)
จำนวนงานต่อเดือน       = ช่องที่ใช้ซ่อมจริง ÷ ช่องเฉลี่ยต่องาน
งานที่มาเสนอบนกระดาน  = จำนวนงานต่อเดือน × 1.3   (ให้ล้นนิดหน่อย ต้องเลือก/ปฏิเสธ)
```

อัตราใช้เวลา: เดือน 1 = 70% (ยังไม่คล่อง · ครั้งแรกของแต่ละงานปิ๊บสอนยาว) · เดือน 2 = 80% · เดือน 3 = 85%

```gdscript
var shift := 1                      # นับรวมทั้งเกม 1–60 (ไม่โชว์ผู้เล่น)
func week() -> int: return (shift - 1) / SHIFTS_PER_WEEK + 1           # 1–12
func month() -> int: return (week() - 1) / WEEKS_PER_MONTH + 1          # 1–3
func work_slots_used_this_month() -> int: ...                           # แถบ 46/160

signal shift_started(month: int, week: int)
signal break_started(kind: StringName)   # &"lunch" · &"afternoon"
signal shift_closed                      # 18:30
signal week_ended(week: int)             # กลับมา — DayLoop ใช้ทำสรุปสัปดาห์ + Chapter
signal month_ended(month: int)           # จ่ายบิล
signal game_ended
```

- `advance_minutes(m)` → ถ้าข้ามช่วงพัก ให้กระโดดข้ามพัก (ยิง `break_started`) · ถ้าข้าม 18:30 ให้หยุดที่ 18:30 แล้วให้ DayLoop ถามว่าจะล่วงเวลาไหม
- `snap_to_slot()` → ปัดขึ้น :00 / :30 ตอนจบงาน
- ช่วง เช้า/บ่าย/เย็น (`TIME` enum เดิม) ใช้ต่อได้ เปลี่ยนเวลาเริ่มเป็น 09:00 · 13:00 · 16:00
- ลบ `current_day` ออกจาก UI · `set_date(day, …)` เปลี่ยนเป็น `set_shift(shift, minute)` (ใช้ตอนโหลดเซฟ/debug)
