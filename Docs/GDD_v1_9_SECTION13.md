## 13.7 ลูกค้าหน้าร้าน — เข้ามาทีละคน · รับได้วันละไม่เกิน 3 งาน

> แทน "กระดานงาน" เดิม (`DayLoop.board` — งานใหม่ขึ้นพร้อมกัน 5/4/3 ใบต่อกะตอนเปิดร้าน + โทรเข้าตอนพักบ่าย) ซึ่งทำให้ผู้เล่นกดรับงานทีเดียวหมด ไม่ได้ฝึกคุยกับลูกค้า และงานล้นมือ

**เหตุผล**
- ช่างจริงเจอลูกค้าทีละคน ต้องฟังอาการ ประเมินเวลาและราคา แล้วตัดสินใจตรงนั้น → ได้ฝึกขั้น BRIEF จริงก่อนเข้ามินิเกม

- เดือน 1–2 ตัวจำกัดคือ cap (3 งาน ≈ 7–13 ช่องจาก 16 ช่อง) → เหลือเวลาว่างให้ไปตลาด อีเวนต์ และกิจกรรม (ข้อ 13.9) · เดือน 3 งาน Lv4–5 ใช้ ~6 ช่องต่องาน ตัวจำกัดกลายเป็นเวลา (3 งาน ≈ 19 ช่อง ต้องล่วงเวลาหรือเลือกงาน)

## 13.8 เป้าหมายรายเดือนและรายจ่ายประจำ

### 13.8.1 เป้าเดือน

- เป้าคือ **เงินเหลือ (กำไร) ของเดือน = รายรับ − ค่าใช้จ่าย**
- เงินที่ซื้ออัปเกรดร้าน · เครื่องราง · ตู้เก็บของ = **เงินลงทุน** ไม่นับเป็นค่าใช้จ่าย → ไม่ลงโทษคนที่ลงทุน และสอนแยก "ค่าใช้จ่าย" กับ "การลงทุน"
- ค่าอะไหล่ที่ลูกค้าจ่ายคืนตอนส่งมอบ = เงินหมุน ไม่นับทั้งรายรับและรายจ่าย

|---|---|---|---|---|---|---|---|
| 1 (สัปดาห์ 1–4) | ~50 | ฿143 | ≈ ฿7,150 | ≈ ฿2,600 | ≈ ฿1,700 | ≈ ฿2,850 | **฿2,000** |
| 2 (สัปดาห์ 5–8) | ~55 | ฿269 | ≈ ฿14,800 | ≈ ฿3,150 | ≈ ฿2,200 | ≈ ฿9,450 | **฿7,000** |
| 3 (สัปดาห์ 9–12) | ~50 | ฿401 | ≈ ฿20,000 | ≈ ฿3,350 | ≈ ฿2,700 | ≈ ฿13,950 | **฿10,000** |
| รวม | ~155 | | ≈ ฿42,000 | | | ≈ ฿26,000 | ฿19,000 |

วิธีคิด: ค่าแรงเฉลี่ย = `DEFAULT_WEIGHTS` × `level_fee` (60/150/300/420/750) · เดือน 1–2 จำกัดด้วย cap 3 (~2.7 งาน/วัน หลังหักวันเนื้อเรื่อง) · เดือน 3 จำกัดด้วยเวลา 16 ช่อง (งานเฉลี่ย ~6 ช่อง → ~2.5 งาน/วัน) · เป้า ≈ 70–75% ของกำไรเมื่อเล่นปกติ · รายรับรวม ≈ ฿42,000 ไม่เกิน MONEY_CAP ฿50,000 ✓
⚠ ทุกตัวเลขเป็นค่าทดลอง — ปรับหลังรันบอทสมดุล (Goal G11)

**สิ่งที่ผู้เล่นเห็น**
- HUD: `เดือน 1 · ฿1,240 / ฿2,000 · เหลือ 9 วัน` + คาดการณ์ `ถ้าทำแบบนี้ต่อ ≈ ฿2,300 ✓`

- แอป **บัญชีร้าน** ในขมOS: รายการรับ–จ่ายรายวัน แยกหมวด (สอนจดบัญชีครัวเรือน) — เปิดใช้หลังอีเวนต์สัปดาห์ 4

### 13.8.3 สิ้นเดือน: ลำดับและผล

ลำดับ: ปิดร้านวันสุดท้ายของเดือน → อีเวนต์ "การไฟฟ้ามาจดมิเตอร์" (เห็นหน่วยไฟ) → **หน้าสรุปเดือน** (รายรับแยกแหล่ง · ค่าใช้จ่ายแยกรายการ · เงินลงทุน · กำไรเทียบเป้า) → **จ่ายบิล** (กดจ่ายทีละใบ เห็นเงินลดทีละขั้น) → ผล

| ผล | เงื่อนไข | เกิดอะไร |
|---|---|---|
| ถึงเป้า | กำไร ≥ 100% ของเป้า | ยายชม · ❤️ +3 · ร้านค้ามีของรอบใหม่ · Achievement |
| เกินเป้า | ≥ 130% | + เครื่องรางพิเศษหรือป้ายร้านแบบใหม่ · ปิ๊บชวน "ลองแบ่งเข้ากระปุกออมสินดูไหม" |
| ไม่ถึงเป้า แต่จ่ายบิลครบ | < 100% | "เดือนติดเหลือง" · ยายให้กำลังใจ + ปิ๊บวิเคราะห์สาเหตุ 1 ข้อ · นับ 1 ครั้ง (strike) |
| เงินไม่พอจ่ายบิล | เงินในมือ < บิล | จ่ายเท่าที่มี ส่วนขาด = ค้างชำระ + ค่าปรับ 10% จ่ายรวมเดือนหน้า · ค้างค่าไฟ → วันแรกเดือนถัดไปไฟถูกตัดครึ่งวัน (รับได้ 2 งาน) · ค้างเน็ต → ร้านออนไลน์ปิด · นับ 1 strike |
| ร้านปิด | strike ครบ 2 ครั้ง (จาก 3 เดือน) | ฉากจบ "ร้านปิด" (มีอยู่แล้วใน `ENDING_TEXT.failure`) |

- strike แรกไม่มีบทลงโทษถาวร — เด็กเล่นต่อได้และมีบทแนะนำ
- โหมดช่วย (หน้าตั้งค่า): เป้าลด 30% · ไม่มีค่าปรับ
